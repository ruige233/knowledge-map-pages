## 二、重点书籍复盘
### 2.1《认知驱动：做成一件对他人很有用的事》· 周岭
- 核心内容摘要：成长的根本是做成事情、创造价值，做到是更高等级的成长。本书以「心法」与「技法」两部分，讲如何通过主动做成一件对他人有用的事来实现成长，并指出缺少价值意识、输出意识、作品意识、利他意识等是多数人无法做成事的根因。本周读到第四章「策略」，聚焦行动力、意义与长期主义。
- 阅读心得：本周最深的是「行动力不是意志力而是清晰力」，模糊的下一步必然导向舒适娱乐。配合「牺牲感转收获感」的视角，把坚持重写成获得，能明显降低行动阻力。想法要落到具体下一步，意义要主动去描述，而不是等它自然出现。
- 本周沉淀：划线 8 条 / 想法 3 条

### 2.2《造浪者：AI创业实战地图》· 梁桂
- 核心内容摘要：面向 AI 创业的实战指南，按认知、选择、构建、增长展开，覆盖赛道定位、算力与人力成本、护城河与产品验证。本周读到成本与现金流、护城河、Agent 产品与评测等章节。
- 阅读心得：这本书把「AI 创业是成本生意」讲得直接，每一次推理都在真金白银地花钱，而护城河不在模型，而在行业理解、数据与工作流嵌入。对做 Agent 产品的启发是，可靠性与人类检查站比界面更值得投入，成本追踪要从第一天做起。
- 本周沉淀：划线 24 条 / 想法 0 条

### 2.3《腾讯技术工程》· 公众号
- 核心内容摘要：腾讯技术官方号，本周内容聚焦多智能体协作与上下文工程，核心命题是上下文如何在人与 Agent 之间低折损流动，以及协作链路上人应承担的分工。
- 阅读心得：最有冲击力的是「消灭转述」的提法：只要还靠总结、转述、再理解，折损就是乘法式累积。解法是让协作各方站在同一份实时上下文上，由群、Topic、@ 构成在场、聚焦、接力的流水线，人只在最后做验收。
- 本周沉淀：划线 14 条 / 想法 0 条

### 2.4《腾讯云开发者》· 公众号
- 核心内容摘要：腾讯云官方社区，本周聚焦大 Agent 时代的研发范式：从确定性工程思维转向科学实验思维，以及 AI 代码的验证、评估与工程体系。
- 阅读心得：核心判断是「从确定性工程思维转向科学的实验思维，是大 Agent 时代研发的分水岭」。被测系统从确定性黑盒变成概率黑盒，需要用对照实验、消融、差分来验证假设，对 AI 产出的验收要落在可验证的工程体系而非感觉。
- 本周沉淀：划线 11 条 / 想法 0 条

## 四、15 条最有价值划线（N = min(round(62×0.25), 15) = 15）
1. **《认知驱动》**（第四章 策略：方法和路径）
   > 因为真正的行动力不是意志力，而是清晰力。也就是说，即便我们清空了工作记忆，如果不清楚下一步具体应该做什么，同样会行动模糊。在这种状态下，我们会觉得做这个也行、做那个也行，最后往往会在强大天性的支配下选择做那些最简单、舒适的活动，娱乐。
   - 心得：行动卡住常不是缺意志力，而是下一步不够清晰。把模糊目标拆成当下唯一可做的动作，行动阻力会明显下降，避免滑向最省力的娱乐。
   - 行动启发：每天写一句「下一步唯一动作」，照做不犹豫。

2. **《认知驱动》**（第四章 策略：方法和路径）
   > 寻找意义就是在训练我们的潜意识，让它领先于我们的能力，牵引我们前进，而不是躲在舒适区拖后腿。所以，要想成为一个长期主义者，就要刻意、主动地多花时间，建设内在的自我，而不是别人说什么自己就信什么。
   - 心得：意义不是空话，是给潜意识装的牵引绳。主动建设内在自我，让它跑在能力前面，长期主义才不会变成靠硬撑的坚持，而是被方向带着走。
   - 行动启发：每周写一次「这件事对我的长远意义」。

3. **《认知驱动》**（第四章 策略：方法和路径）
   > “戒烟的核心在于意识到戒烟不是一种牺牲，不是一种权利被剥夺，而是一种收获与解放。”换言之，如果你在做一件事情的时候感觉到自己是在坚持，其实就有牺牲感了。你会觉得早起是在牺牲温暖舒适的被窝，阅读是在牺牲手机娱乐的轻松，锻炼是在牺牲舒适慵懒的时间……
   - 心得：坚持感本身就是牺牲感的信号。把阅读、锻炼从「失去」重写成「获得」，心态一转，行动就不再需要对抗，做起来也更可持续。
   - 行动启发：把要做的事改写成「获得」句式再执行。

4. **《认知驱动》**（第四章 策略：方法和路径）
   > 一个人的成就往往在他的眼界之内，一个人在现实世界中能走多远，其实在他心里早就标记好了。
   - 心得：眼界是成就的隐形上限，心里没标记，现实里很难走到。先想清楚想抵达的位置，把目标显性化，行动才有方向，也能反过来校正路径。
   - 行动启发：写下本季度想抵达的一个具体位置，常回头看。

5. **《造浪者》**（第13章 现金流为王 AI创业者的生存财务课）
   > 忽略监控。不知道每个功能、每个用户、每次调用花了多少钱，就无法优化。从第一天就给API调用加上成本追踪，按功能、按用户、按模型。这不需要复杂的系统，一个简单的日志+每周汇总就够了。
   - 心得：成本看不见就无从优化。从第一天用日志加每周汇总做成本追踪，按功能、用户、模型拆分，小成本就能拿到优化抓手，避免规模上来后成本失控。
   - 行动启发：给调用加日志，每周汇总一次成本分布。

6. **《造浪者》**（第13章 现金流为王 AI创业者的生存财务课）
   > 实现方法是在你的后端加一个“路由层”，根据任务复杂度自动分配模型。
   - 心得：模型成本的关键杠杆是路由。按任务复杂度自动分配模型，简单任务走轻量模型，复杂任务才上大模型，能在不牺牲效果的前提下显著压低成本。
   - 行动启发：为调用设计任务复杂度路由，先简单后复杂。

7. **《造浪者》**（第11章 护城河 AI企业的持久竞争优势）
   > 在AI时代，技术是入场券，不是护城河。护城河来自技术之上的所有东西，行业理解、客户关系、工作流嵌入、数据积累、品牌信任。
   - 心得：技术会被快速追平，真正难复制的是技术之上的积累。把精力放在行业理解、客户关系与工作流嵌入上，比追逐模型优势更可能形成长期壁垒。
   - 行动启发：盘点并加码一项技术之外的积累。

8. **《造浪者》**（第9章 Agent与龙虾 当AI从回答变成执行）
   > “3AM测试”，如果这个操作在凌晨3点被Agent自动执行了，而你第二天早上才发现，最坏的后果是什么？
   - 心得：自动执行的可靠性，要看最坏情况下的代价。用「凌晨3点被自动执行、第二天才被发现」倒推风险，就能定位哪些操作必须加防护与告警。
   - 行动启发：给自动执行的操作做一次最坏后果推演。

9. **《造浪者》**（第9章 Agent与龙虾 当AI从回答变成执行）
   > 在Agent工作流中，哪些环节必须设置“人类检查站”，Agent必须暂停，等待人类确认后才能继续？
   - 心得：可靠性来自明确设卡，而不是默认全自动。提前标出必须人确认的环节，让 Agent 在这些点暂停，既保留自动化效率，又守住关键决策的边界。
   - 行动启发：为流程标出必须人工确认的检查点。

10. **《造浪者》**（第一篇 认知 理解AI创业的独特地形）
   > 私有数据飞轮。这不是简单的“有很多数据”，而是一个动态循环：你的产品产生独特的用户交互数据，这些数据用于改进模型，模型改进带来更好的体验，更多用户使用产生更多数据。
   - 心得：数据的价值不在存量而在循环。只有形成「产品产生独特数据、数据改进模型、模型带来更好体验」的正向飞轮，数据才会持续增值，否则只是躺在库里。
   - 行动启发：检查产品是否已跑通数据到模型的闭环。

11. **《腾讯技术工程》**（公众号）
   > 当上下文能够共享、能够接力，剩给人的，是机器给不了的四件事：定目标，这件事到底要解决什么，值不值得做。做判断，方案对不对、取舍合不合理、结果能不能接受。划边界，什么能做、什么不能碰、红线在哪。做验收，最后拍板的那一下，责任落在人身上。
   - 心得：人被替代的不是搬运，而是判断与责任。上下文能接力后，人应聚焦定目标、做判断、划边界、做验收这四件机器给不了的事，这才是协作中人的价值所在。
   - 行动启发：把时间留给判断与验收，别做转述中继。

12. **《腾讯技术工程》**（公众号）
   > 群、Topic、@三者合起来，构成了一条低折损的上下文流水线：上下文在场（群）、上下文聚焦（Topic）、上下文接力（@）。这不是三个功能的堆叠，是同一个协作哲学的三个切面。
   - 心得：低折损协作的关键是让上下文在场、聚焦、接力连续流动。把协作组织成同一份实时上下文上的接力，而不是层层转述，才能把信息损耗降到接近零。
   - 行动启发：用共享上下文替代转述，让下一棒直接进入现场。

13. **《腾讯技术工程》**（公众号）
   > 所以真正的解法不是优化转述，是消灭转述：让协作的各方，人也好、Agent也好，站在同一份实时的上下文之上。不是把上下文从一个脑子搬到另一个脑子，而是让它从一开始就摆在一个大家都能看见的地方。
   - 心得：转述的损耗靠优化无法根除，只能消灭。把上下文摆在各方都能看见的同一处，协作从「我告诉你」变成「我们看着同一现场一起干」，折损自然消失。
   - 行动启发：关键协作落到同一处共享上下文，不再互相转述。

14. **《腾讯云开发者》**（公众号）
   > 我越来越意识到，从确定性工程思维转向科学的实验思维，就是大 Agent 时代研发最核心的分水岭。
   - 心得：大 Agent 时代被测系统从确定性变成概率性，靠固定输入固定输出的工程思维已不够。转向定度量、做对照、用实验证伪的实验思维，才是驾驭不确定性的关键。
   - 行动启发：把业界直觉当假设，用对照实验去验证。

15. **《腾讯云开发者》**（公众号）
   > 第一，科学的实验思维到底体现在哪里？它体现在一整套严密的推演闭环里：先定度量标准，再做工程设计，直接排除不靠谱的业界常规方案；把行业直觉当成待验证的假设，用对照实验证伪，没有所谓的业界权威；运用差分法、统计分布、消融实验等科学实验方法，去验证每一种猜想。
   - 心得：实验思维的落地是一整套推演闭环：先定度量，再做设计，用对照实验与消融去证伪猜想，不盲信权威。这套方法能让 AI 研发的决策从经验变成可验证。
   - 行动启发：每个方案先定度量，再用对照实验验证。
