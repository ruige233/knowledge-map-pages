# 万字详解 10 道 AI Agent 高频面试题

> 一句话定位：10道AI Agent高频面试题：本质、选型、范式、工具、记忆、RAG、评估

## 摘要

本文把 AI Agent 面试高频考点整理成 10 道题，分三层：是什么（Agent 本质、选型、四种范式）、怎么干（Function Calling、MCP、容错防循环、记忆）、怎么变好（上下文、RAG、评估）。核心结论：Agent 与普通 LLM 应用的差别在自主决策和闭环；路径写死用 Workflow、需自主决策上单 Agent、有新增信息才上多 Agent；模型只做决策不执行，FC 在模型侧、MCP 在工具侧；RAG 核心是检索对的那段；评估看 Pass^k。

## 要点

- AI Agent 与普通 LLM 应用的本质区别是有无自主决策、目标驱动和循环闭环，而非组件多少。
- 选型看路径是否可预定义：写死用 Workflow，需自主决策用单 Agent，拆出新增信息才用多 Agent。
- CoT 管想、ReAct 加上做、Plan-and-Execute 先想全局、Self-Refine 做完再审，生产环境混合使用。
- Function Calling 中模型只做决策不执行，真正干活的是预先写好的函数，Pydantic 校验有格式与业务两道闸。
- MCP 与 FC 正交：FC 在模型侧表达调用意图，MCP 在工具侧标准化接入；工具一多靠路由策略控成本。
- 容错分解析失败与执行失败，防死循环靠最大轮次、完成标记、结果校验、人工介入四道防线。
- 判断是否记忆看会不会被语义检索出来影响下次决策；上下文腐化不报错更隐蔽，隔离优于压缩。
- RAG 核心是检索到对的那段：向量+BM25+RRF+重排；评估 Agent 应看 Pass^k 而非 Pass@k。

## 提炼

> 一句话定位：10道AI Agent高频面试题：本质、选型、范式、工具、记忆、RAG、评估

### 分节提炼

- **01 AI Agent 本质**：Agent 关键三词：自主决策、目标驱动、循环闭环；循环源于 LLM 自回归生成机制，非人为设计；权重冻结不会自我训练，记忆/工具/流程才会积累
- **02 Workflow/单/多 Agent 选型**：路径固定用 Workflow，分支由结果决定用单 Agent；单 Agent 指一个决策中心，仍可多轮调工具；拆多 Agent 前问：有无新信息、为何不自审、换角色够不够；多 Agent 三种搭法：对等协作、管理者、去中心化
- **03 四大推理范式对比**：CoT 纯推理不调工具，是各范式地基；ReAct 加做和看，代价是死循环、token 滚大、一步带偏；Plan-and-Execute 先 Planner 列清单再 Executor 执行，Re-planner 修正；Self-Refine 在评审层做→审→改，即 Reflection 实现
- **04 Function Calling 全流程**：铁律：模型只做决策，不执行；LLM 只产出调用意图 JSON，框架代码按 JSON 调预写函数；Pydantic 校验发生在返回参数后，管格式；业务合法性在函数内再查
- **05 MCP 与 FC 关系**：MCP 是工具接入的开放协议，类比 USB-C；FC 模型侧、MCP 工具侧，两者正交可配合；工具体系三维度：工具形态、接入协议、路由策略；路由三种：分层下钻、按需检索、命名空间
- **06 容错与防死循环**：先分失败位置：解析失败在执行前，执行失败在函数报错后；超时指数退避重试，全败回喂模型软失败；数据太大在进 LLM 前瘦身：工具层精简、Agent 层摘要、超大落盘；四道防线：轮次上限、完成标记、结果校验、人工介入
- **07 记忆/知识库/日志**：短期记忆=对话窗口，长期记忆=用户偏好，知识库=公共文档，日志=流水账；判断记忆唯一标准：会不会被检索出来影响下次决策；生命周期：写入、检索、淘汰（衰减/合并/容量）；冲突处理追加+检索时推理比写入时消歧更安全
- **08 上下文溢出与腐化**：溢出装不下会报错，腐化装得下找不到且不报错；治溢出三件套：滑动窗口、摘要压缩、记忆外置；隔离优于压缩：委派子 Agent 让中间信息不进主上下文；KV Cache 三铁律：system 不改、动态信息追加、用标准 API
- **09 RAG 链路与优化**：RAG 是开卷考试，核心是检索到对的那一段；离线建索引+在线查询：召回 top 20-50 再重排 top 3-5；向量管语义、BM25 管字面，RRF 融合两路排名；重排用跨编码器精读；Agentic RAG 让模型决定查不查
- **10 Agent 评估与迭代**：指标：任务完成率为硬指标，延迟/调用次数/token/幻觉率为护栏；验证器拆 FAIL_TO_PASS 与 PASS_TO_PASS 两个命题；评测可自动化、优化不能自动化；归因归首个错误且归对层
- **11 三层骨架总结**：十道题三层骨架：是什么→怎么干→怎么变好

### 带走三句话

1. Agent 与普通 LLM 应用的差别在自主决策和闭环；路径写死用 Workflow，有新增信息才上多 Agent。
2. 模型只做决策不执行，FC 在模型侧、MCP 在工具侧；防跑飞靠四道防线，隔离优于压缩。
3. 记忆看是否影响下次决策，RAG 核心是检索对；评估看 Pass^k，归因归首个错误且归对层。
