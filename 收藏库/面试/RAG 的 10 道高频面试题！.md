# RAG 的 10 道高频面试题！

> 一句话定位：RAG 十大高频面试题：从基础认知、核心流程到优化评估与生产落地全覆盖。

## 摘要

本文面向金三银四大厂面试，梳理 RAG 十大高频面试题，每题配标准答案、Java 代码示例、加分点与避坑指南。内容分五篇：基础认知篇讲 RAG 定义及其解决的知识时效性、幻觉、私有数据访问三大痛点，并对比微调 SFT 的选型与组合实践；核心流程篇拆解索引与检索生成两阶段，含分块、向量化、Rerank、Prompt 构建等环节；优化与评估篇给出 Chunk 策略、混合检索、查询重写、Rerank、HyDE 等提效手段，以及 Recall@K、MRR、NDCG 与 Ragas RAG Triad 评估指标，并罗列十大常见问题与解法；高级机制篇介绍 Self-RAG、CRAG、Graph RAG 与 Spring AI Alibaba 生产落地；总结篇给出按题型分类的备考思路，强调动手完整实现 RAG 系统。

## 要点

- RAG 定义：先检索外部知识库，再把检索内容与问题一起交给大模型基于真实资料生成答案。
- RAG 解决三大痛点：知识时效性、幻觉、私有数据访问问题。
- RAG 与微调 SFT 路线不同：参数不动、知识外置、可溯源 vs 标注训练、延迟低；生产可组合使用。
- 完整流程分索引（离线）与检索生成（在线）两阶段，关键环节包括分块、向量化、向量检索、Rerank、Prompt 构建、LLM 生成。
- Chunk 推荐参数：chunk_size=512~1024，overlap=100~200；可选固定、递归、语义、结构、Parent-Child 策略。
- 提升检索准确率四法：混合检索、查询重写、Rerank、HyDE；混合检索可使召回率从 65% 提升至 82%。
- 评估覆盖检索（Recall@K/MRR/NDCG）、生成（Ragas Triad：忠实度、答案相关性、上下文召回率）与端到端三层次。
- 高级机制 Self-RAG、CRAG、Graph RAG 各解其困；用 Spring AI Alibaba 可完成生产级 RAG 系统。

## 提炼

> 一句话定位：RAG 十大高频面试题：从基础认知、核心流程到优化评估与生产落地全覆盖。

### 分节提炼

- **01 RAG 基础认知**：RAG 核心流程：生成前先从外部知识库检索相关内容，再把内容与问题一并交给大模型生成。；三大痛点：知识时效性、幻觉、私有数据访问。；RAG 参数不动、知识外置可溯源；SFT 用标注数据训练、延迟低；生产可先 SFT 定风格再 RAG 供知识。
- **02 RAG 核心流程**：分两大阶段：索引阶段（离线）与检索生成阶段（在线）。；索引：文档加载、文本分块、向量化、向量存储。；检索生成：Query 处理、向量检索、Rerank、Prompt 构建、LLM 生成。；分块推荐 chunk_size=512~1024，overlap=100~200。
- **03 优化与评估**：Chunk 策略：固定长度、递归、语义、结构、Parent-Child，各适其用。；提准确率：混合检索、Query Rewrite、Rerank、HyDE；混合检索召回率 65%→82%。；评估指标：Recall@K、MRR、NDCG 与 Ragas Triad（忠实度、答案相关性、上下文召回率）。；十大问题按原因对症解决：内容缺失、脱离上下文、SQL/表格弱、复杂 PDF 提取难等。
- **04 高级机制**：Self-RAG 输出反思 Token 自评检索质量，决定是否再次检索。；CRAG 在检索质量差时自动纠错：Web Search Fallback 或知识图谱推理补全。；Graph RAG 以实体-关系-实体三元组图遍历检索，多跳推理强、可解释。；Spring AI Alibaba 按依赖、配置、服务、REST API 四步实现生产级 RAG。
- **05 总结**：十题覆盖基础原理→核心流程→检索优化→评估体系→高级机制→生产落地。；按基础认知、核心流程、优化评估、高级机制、生产落地分类准备。；最终建议：不要只背答案，动手实现完整 RAG 系统。

### 带走三句话

1. 答 RAG 要有深度：讲清检索什么、怎么检索、为什么能抑制幻觉，并能说出演进路线。
2. RAG 与 SFT 不是二选一：先 SFT 定领域风格，再 RAG 供实时知识，是生产常见组合。
3. 别只背答案：用 Spring AI Alibaba 从文档索引到智能问答完整实现一遍。
