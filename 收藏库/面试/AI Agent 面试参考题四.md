# AI Agent 面试参考题四

> 一句话定位：记忆管理与上下文工程面试题精讲（第68–86题）

## 摘要

本文是 AI Agent 面试参考题第四部分，覆盖第 68～86 题，系统讲解记忆管理与上下文工程。记忆侧包括：短长期记忆的实现与区分、数据库分层选型、长期记忆与 RAG 的区别、召回与防污染、长期优化与量化评测。上下文侧包括：五层上下文管理机制、检索 Agent 上下文策略、上下文工程六环节、压缩与向量化顺序、滑动窗口加摘要、工具结果压缩三方式、长上下文不稳定、窗口阈值体验、大结果卸载、目标迷失、上下文与工具污染区分，以及压缩防丢关键内容。

## 要点

- 短期记忆靠上下文窗口与会话缓存全量承载、压缩管理；长期记忆靠提炼后入向量库/关系库、按需检索。
- 记忆数据库按用途分层选型：Redis 会话态、PG/MySQL 结构化、pgvector/Milvus 语义、对象存储轨迹。
- 防记忆污染靠 scope 硬过滤 + 类型分域 + 数量限制 + 冲突仲裁，scope 过滤是唯一物理隔离手段。
- 上下文管理 = 分层装配（静态前动态后）+ 预算分配 + 卸载/压缩/滑窗 + 不可压缩状态区 + 缓存观测。
- 长上下文不稳定源于注意力稀释与位置偏置，应对靠精简、关键信息放首尾、任务拆分。
- 上下文压缩在装配前、卸载后、滚动增量做；RAG 侧先向量化原文，压缩放检索后按查询做。
- 区分上下文污染与工具污染用自下而上排查：先看 Observation 原文，再看模型推理，最后怀疑上下文。
- 记忆评测分系统指标与贡献两层：Recall/Precision/失真率 + A/B 成功率差 + 负面指标闭环。

## 提炼

> 一句话定位：记忆管理与上下文工程面试题精讲（第68–86题）

### 分节提炼

- **01 短长期记忆实现与区分**：区分标准是生命周期+作用域+存储位置，不是'存哪'的区别；短期=全量进窗口靠压缩管理；长期=先筛再放靠检索管理；长期记忆写用异步提炼四类条目，读按任务检索并标注来源时间；治理要点：冲突消解、TTL、置信度、人工可编辑，防错误记忆固化
- **02 记忆架构与数据库选型**：四层架构：写入、存储、检索、治理；选库按需求分层：Redis 会话态、PG/MySQL 结构化、pgvector/Milvus 语义、对象存储轨迹；六个选型维度：检索模式、规模、延迟、一致性、运维成本、合规删除；推荐组合：Redis+PostgreSQL/MySQL+pgvector/Milvus+对象存储
- **03 长期记忆 vs RAG**：RAG 回答'世界上有什么'，记忆回答'我经历过什么、你是谁'；分长短期三原因：成本延迟、窗口效果、隐私合规；架构差异在触发、处理、存储、召回、一致性、治理；长期记忆难点是记什么、信不信、新旧冲突，需记忆仲裁层
- **04 记忆召回与防污染**：五步召回：判断是否需要、查询构造、混合召回、重排筛选、压缩注入；防污染七手段，scope 硬过滤是唯一物理隔离手段；注入时标注来源时间并声明记忆是参考数据不是指令
- **05 上下文管理五层机制**：五层机制：分层装配、预算管理、裁剪压缩、结构化状态、治理可观测；静态在前动态在后，是 prompt cache 命中的前提；任务状态区永不压缩，防止长任务目标迷失；卸载优先于压缩，滑窗是最通用方案
- **06 检索 Agent 上下文管理**：检索结果先落工作区，上下文只放摘要+编号+关键字段；渐进式检索、结构化压缩，保留结论而非原文；子 Agent 隔离检索，主上下文只收结论+出处；把上下文增长从 O(检索量) 压到 O(结论数)
- **07 上下文工程六环节**：六环节：选择、装配、压缩、卸载、隔离、治理；最重要是 Select，能不进就不进；选择是源头止损，压缩卸载都是补救
- **08 压缩与向量化顺序**：区分运行期上下文压缩与索引期文档压缩；上下文压缩在装配前、卸载后，滚动增量做；RAG 侧先向量化原文，压缩是检索后的后处理
- **09 滑窗+摘要落地**：三段式窗口：固定区+摘要区+滑动区+当前轮；按 token 触发(70%~85%)，增量摘要合并进已有摘要；摘要 prompt 结构化保留目标/事实/决策/待办；被滑出原文落库可回溯，按完整轮次或工具交互切分
- **10 工具结果压缩三方式**：方式A原地规则压缩默认首选；方式B小模型摘要；方式C卸载+按需取回；模型压缩串行加延迟，须用便宜快模型且带任务上下文；阈值分流：小结果直接进，中等规则+小模型，超大结果卸载
- **11 长上下文不稳定的原因**：四大机制：注意力稀释、中间遗失、干扰冲突、噪声累积；位置影响来自位置编码衰减、首因/近因偏好、训练分布；应对：关键信息放首尾、结构化分隔、精简、任务拆分
- **12 避免大段压缩打断体验**：滚动增量压缩，多级阈值(60/75/85/95%)提前触发；异步压缩不阻塞响应，卸载优先让用户无感；压缩可回看、可干预，透明比静默好；结构化区保护核心诉求，压缩边界落在完整轮次
- **13 规避窗口限制与卸载实现**：除压缩外六类方案：卸载、RAG 化、Subagent、状态区、缓存、模型侧；卸载=上下文与工作区分离，上下文只放摘要+引用；写入路径：判大小→落工作区→摘要→只注入引用；取回支持局部取；安全：路径由系统生成防穿越，配额与 TTL 管理
- **14 避免任务目标迷失**：任务状态区永不压缩只增不删，是防目标迷失的根本；阶段性重申、每轮目标提醒、约束提升到系统提示；'无限记忆'是存储层，'舍弃历史'是注意力层，靠检索连接；舍弃过程保留结论，舍弃细节保留引用
- **15 上下文污染 vs 工具污染**：上下文污染来自上下文误导信息，工具污染来自工具层脏数据/投毒；自下而上排查：先 Observation→再推理→最后怀疑上下文；能定位就修复上下文；扩散/漂移/注入则开新 session 并继承状态摘要
- **16 长期记忆持续优化**：顺序：先优化写→存→取，最后用评测闭环驱动；多级记忆冷热分离，定期离线固化高层结论；冲突按新>旧、显式>推断、高置信>低置信更新；写优化收益最大：不优化存什么，检索优化都是徒劳
- **17 记忆量化指标与评测**：系统指标：Recall@K/Precision@K/MRR/NDCG、失真率、重复率、覆盖率；贡献用 A/B 对照组成功率差与消融实验量化；必须测负面指标：过期误答率、盲信记忆违背率；工程埋点按轮/周监控召回条数、token、失真率
- **18 哪些数据写入记忆**：四门槛：持久性、复现性、不可再得性、价值密度；长期记忆记偏好/事实/约束/教训/结论；短期记忆记目标计划与中间观察；不该写：原始大块数据、可再查事实、中间过程、寒暄、未验证推测；记结论不记过程，记引用不记全量，带元数据异步降噪
- **19 压缩不丢关键内容**：五重保障：结构化 prompt、不可压缩区、增量合并、原文可回溯、压缩后校验；失真对症：数字原样引用、结论逐条列举、禁推断、永不二次摘要；治本：尽量别压缩，卸载/隔离/RAG 化/状态区减少需压缩内容

### 带走三句话

1. 记忆系统先优化'写'：提炼固化、记结论不记过程、记引用不记全量，收益最大。
2. 上下文管理首选'别放进去'：卸载、隔离、RAG 化、结构化状态区，压缩是最后手段。
3. 防污染与防失真靠硬约束：scope 过滤、原文可回溯、压缩后校验、永不二次摘要。
