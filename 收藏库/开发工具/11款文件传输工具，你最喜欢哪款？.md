# 11款文件传输工具，你最喜欢哪款？

> 一句话定位：11款文件传输工具速览：FTP、局域网、扫码、匿名、P2P各有所选

## 摘要

推荐11款文件传输工具，覆盖FTP、局域网、扫码、匿名与P2P等场景。FileZilla是免费开源FTP客户端/服务器，支持FTPS与SFTP；百灵快传基于Go语言，扫码即可与电脑互传大文件；LFTP是类Unix命令行FTP客户端，支持FTPS、HTTP、SFTP等多种协议；trzsz.js兼容tmux并有进度条；NitroShare跨平台自动发现局域网设备；OnionShare经Tor匿名共享文件；croc端到端加密、免端口转发；tl-rtc-file用WebRTC在web端P2P传超大文件。

## 要点

- 文件传输工具按场景选型：FTP、局域网、扫码、匿名、P2P 各有对应工具。
- FileZilla 是免费开源的 FTP 客户端/服务器，支持 FTP、FTPS、SFTP。
- 百灵快传基于 Go 语言，手机扫码即可与电脑互传大文件，适合局域网场景。
- LFTP 是类 Unix 命令行 FTP 客户端，支持 FTPS、HTTP、HTTPS、SFTP、FXP 等协议并内置 BitTorrent。
- lftp 常用命令：用户名@主机登录、mget -c 续传下载、put 上传。
- trzsz 兼容 tmux，有进度条并支持目录传输与拖拽上传。
- qrcp 扫码经 Wi-Fi 互传；NitroShare 跨平台、自动发现局域网设备并可传整个目录。
- OnionShare 经 Tor 匿名分享；croc 端到端加密免端口转发；tl-rtc-file 用 WebRTC P2P 分片传超大文件。

## 提炼

> 一句话定位：11款文件传输工具速览：FTP、局域网、扫码、匿名、P2P各有所选

### 分节提炼

- **01 FileZilla FTP 工具**：免费开源，分为客户端与服务器两个版本。；客户端支持 FTP、FTPS、SFTP，界面有条理、便于管理多站点。；服务器版小巧可靠，支持 FTP 与 SFTP。
- **02 百灵快传 B0Pass**：基于 Go 语言，定位手机电脑超大文件传输与局域网共享。；电脑双击执行、手机扫码即可双向传输大文件。
- **03 LFTP 命令行工具**：类 Unix 命令行 FTP 客户端，GPL 发布。；除 FTP 外支持 FTPS、HTTP、HTTPS、SFTP、FXP，并内置 BitTorrent 客户端。
- **04 普通用户登录**：lftp tom@192.168.1.17 以普通用户登录，随后输口令。；进入交互提示符后用 ls 列出远端目录。
- **05 下载与上传**：mget -c 文件名可下载，-c 表示断点续传。；put 文件名把本地文件上传到远端目录。
- **06 trzsz.js**：trzsz（trz/tsz）兼容 tmux，类似 lrzsz（rz/sz）。；有进度条，支持目录传输与拖动上传。
- **07 qrcp 扫码传输**：扫描终端二维码，通过 Wi-Fi 在 PC 与移动设备间传输。；同时支持发送与接收。
- **08 NitroShare 局域网**：基于 Qt，支持 Windows、OS X 与 Linux。；自动发现局域网设备，界面直观，可传输整个目录。
- **09 FileCodeBox 快递柜**：轻量级文件快递柜，以匿名口令分享文本与文件。；像拿快递一样凭口令取文件。
- **10 Bigfile 管理系统**：Golang 开发的文件传输管理系统。；支持 HTTP API、RPC 调用与 FTP 客户端管理文件。
- **11 OnionShare 匿名分享**：开源工具，可安全匿名共享任意大小文件。；启动 Web 服务器作为 Tor onion 服务，生成临时 URL。；文件托管本机，对方用 Tor 浏览器访问下载。
- **12 croc 跨平台**：任意两台电脑间简单安全传输文件与文件夹。；端到端加密、多文件传输、支持中断恢复。；无需本地服务器或端口转发。
- **13 tl-rtc-file**：使用 WebRTC 在 web 端 P2P 点对点传输。；分片传输、跨终端、不限平台、内网不限速，支持私有部署与二次开发。

### 带走三句话

1. 按场景选型：FTP 用 FileZilla 或 LFTP，局域网互传选百灵快传、NitroShare。
2. 重安全选 OnionShare（Tor 临时 URL）或 croc（端到端加密、免端口转发）。
3. 大文件与终端：tl-rtc-file 用 WebRTC P2P 分片，trzsz 兼容 tmux 带进度条。
