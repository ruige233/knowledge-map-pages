# 听说 GitHub 上阅读源码很费劲？

> 一句话定位：三个在线工具：github.dev 看源码、htmlpreview 渲染 HTML、gitpod 云上运行。

## 摘要

本文介绍三个让 GitHub 源码阅读更省力的在线工具。第一个是 github.dev：在任意 GitHub 仓库页面按下键盘句号键，等几秒即可在浏览器里打开 VSCode 界面直接阅读源码，不必下载仓库到本地。第二个是 htmlpreview.github.io：把 GitHub 上的 HTML 文件地址拼到该网址后面，就能看到渲染后的页面效果，而不是密密麻麻的源代码，适用于 openjdk 的 build 说明这类 HTML 文档。第三个是 gitpod.io：提供在线开发环境，输入仓库地址即可搭建并运行项目，作者以 spring-petclinic Java 项目为例，说明需按提示安装 idea 插件后即可运行。此外还提到 bito、copilot 等 AI 辅助工具可通读整仓库代码答疑，claude 在代码生成领域表现突出。

## 要点

- 在 GitHub 仓库页按句号键，几秒后进入 github.dev 在线读源码。
- github.dev 免去把源码下载到本地再阅读的麻烦。
- htmlpreview.github.io 可把 GitHub 上的 HTML 文件渲染成页面效果。
- gitpod.io 提供在线开发环境，输入仓库地址即可直接运行项目。
- 以 spring-petclinic Java 项目为例，gitpod 需按提示安装 idea 插件后运行。
- AI 辅助工具 bito、copilot 可通读整仓库代码并答疑，claude 生成代码水平高。

2. 看 HTML：把文件地址拼到 htmlpreview.github.io/? 后面即可渲染。
3. 要运行：gitpod.io 输入仓库地址，云上直接跑起来。
