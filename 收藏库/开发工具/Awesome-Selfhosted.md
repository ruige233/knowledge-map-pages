# Awesome-Selfhosted

> 一句话定位：自托管领域最知名的精选清单，收录可在自己服务器上部署的自由/开源网络服务与 Web 应用。

## 摘要

awesome-selfhosted 是自托管（self-hosting）领域最具代表性的精选清单（awesome list），收录可在自己服务器上部署的自由软件——网络服务与 Web 应用，用于替代各类 SaaS 供应商。仓库 2015 年 6 月创建，至今仍在活跃维护，已积累 32 万+ stars、1.5 万+ forks。清单按上百个分类组织（分析、备份、博客、CMS、邮件、媒体流、Wiki、VPN 等），每个条目标注 SPDX 许可证与部署方式（语言 / Docker / K8S 等）。它只收自由软件，非自由软件单独放在 non-free.md 页面。官方推荐使用 HTML 版 awesome-selfhosted.net，仓库 Markdown 版为 legacy；清单本身以 CC-BY-SA-3.0 授权，配套的 awesome-selfhosted-data 仓库通过自动化检查死链与未维护项目来保证质量。

## 要点

- 自托管定位：在自己服务器上托管、管理应用以替代 SaaSS 供应商；清单只收 Free Software，非自由软件单独列在 non-free.md。
- 规模：约 32.6 万 stars、1.5 万 forks（截至 2026-10-15），按上百个分类组织，从 Analytics、Email 到 Wiki、VPN。
- 条目格式：每条标注许可证（SPDX 短标识）与部署环境（语言 / Docker / K8S 等），并提供 Demo 与源码链接。
- 推荐入口：HTML 版 https://awesome-selfhosted.net/ 为官方推荐形式，GitHub 仓库 Markdown 版是 legacy。
- 维护机制：数据与死链/未维护项目检查拆到 awesome-selfhosted-data 仓库，通过 GitHub Actions 自动化保证质量。
- 清单本身以 CC-BY-SA-3.0 授权，贡献规范见 awesome-selfhosted-data/CONTRIBUTING.md。

## 注意

- stars/forks 为 GitHub API 抓取时的实时快照值（2026-10-15），随时间滚动变化，非固定数值。
- 清单正文体量极大（约 33 万字符），本条目仅收录其定位、结构与维护方式，未逐条罗列所收录软件。
