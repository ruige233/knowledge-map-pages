# DeepGEMM

> 一句话定位：DeepSeek 开源的 GPU 张量核心内核库，把大模型训练/推理里最吃性能的几种矩阵运算整合成一套干净高效的 CUDA 代码。

## 摘要

DeepGEMM 要解决的是大模型底层算子分散、调优成本高的问题：它把 FP8、FP4、BF16 精度的矩阵乘法、MoE 相关的融合运算以及 MQA 评分等关键计算原语收进同一个 CUDA 代码库，用统一实现替代各框架里零散的专家手写内核。性能上，官方给出的数据是在 H800 上最高可达 1550 TFLOPS，并且优于人工专家调优的实现。它最值得注意的设计是 Mega MoE 融合内核：把 EP 分发、线性计算、SwiGLU 激活、EP 合并这四步合成一个 mega-kernel，让通信与计算重叠执行，从而压低 MoE 层的实际耗时。工程可用性方面，它不需要用户手动编译 CUDA，采用 JIT 运行时自动编译，安装流程很短。代价是硬件门槛明确——依赖 NVIDIA SM90 及以上架构，需要 H100、H800、B200 一类 GPU。热度上这是相对小众但专业的底层库，2026-10-02 快照约 8.0k stars、1.3k forks，MIT 许可，主语言为 Cuda。

## 要点

- **统一内核库**：FP8 / FP4 / BF16 矩阵乘法、MoE 融合、MQA 评分等原语集中在一套 CUDA 实现中，避免多框架重复造轮子。
- **性能数据**：H800 上最高 1550 TFLOPS，官方称优于专家手工调优的同类库。
- **Mega MoE 融合**：EP 分发 → 线性计算 → SwiGLU 激活 → EP 合并合成单个 mega-kernel，通信与计算重叠，降低 MoE 层开销。
- **JIT 运行时分发**：无需手动编译 CUDA，运行时自动编译，安装配置成本低。
- **硬件门槛**：仅支持 NVIDIA SM90 及以上，即 H100 / H800 / B200 一类的数据中心 GPU。
- **许可与关注度**：MIT，2026-10-02 快照约 8.0k stars / 1.3k forks，创建于 2025-02-13。
