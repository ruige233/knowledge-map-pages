# 达尔文.skill 2.0

> 一句话定位：把 Karpathy autoresearch 的自主实验循环搬到 Agent Skills 优化上——评估→改进→测试→保留或回滚，让 Skill 质量只升不降。

## 摘要

达尔文.skill 是一个用于优化 Agent Skills 的 SKILL，受 Karpathy autoresearch 启发，把「只保留可测量改进」的棘轮机制从模型训练搬到 SKILL.md 维护上。它同时评估结构质量（9 维加权评分，满分 100）与实际效果（跑测试提示词看输出），每一轮只改一个维度、由 2 个独立子 agent 评委打分，新分高于旧分才保留，否则 `git revert` 回滚。v2.0 系统性吸收了微软研究院 SkillLens 与 SkillOpt 两篇论文：新增失败模式编码、可执行具体性、高风险行动黑名单三个维度，并对齐 validation-gated 的多评委独立审查与早停机制。与传统全自主方案不同，它强调 human-in-the-loop——关键阶段强制暂停等用户确认。实测中 huashu-gpt-image skill 从 80.8 提升到 91.65，darwin 自评从 86.05 提升到 92.7。

## 要点

- 核心循环：结构评分 + 效果验证 + 棘轮机制（keep/revert），分数只升不降；映射自 autoresearch 的 program.md / train.py / val_bpb / git ratchet / test set。
- 9 维评估体系：v2.0 吸收 SkillLens 实证 rubric，新增「失败模式编码」「可执行具体性」「高风险行动黑名单」，明文禁止模糊措辞与 rm / force push 等破坏性操作。
- Human in the loop 三层守关：Phase 1 基线评估、Phase 2 单维度优化后 CHECKPOINT 暂停、Phase 3 回归测试涨幅低于阈值强制停手。
- 反例黑名单 8 条：禁止同一个 AI 又改又评（LLM 自评准确率仅 46.4%）、禁止 `git reset --hard` 回滚（用 `git revert`）、一轮只改一个维度、干跑比例 >30% 告警等。
- 实测数据：huashu-gpt-image 80.8→91.5→91.65（+10.85），darwin 自评 86.05→92.05→92.7；单轮涨幅 <1 分自动早停。
