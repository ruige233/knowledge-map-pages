# Agent评测漫谈 —— 由浅入深讲解Agent评测

> 一句话定位：美团图灵团队科普Agent评测：观测为基、搭桥对齐、长程Agent走向行为评测。

## 摘要

本文是美团图灵Agent评测团队的科普文章。评测核心目的是回答Agent好不好、哪里好哪里不好，为迭代指明方向；评测对象已从单一模型变为“模型+系统+工具+流程”的复杂系统，需覆盖结果、过程、效率、风险四层。方法论上，指标核心是搭桥而非堆指标，客观与主观评测并行，并用“人人一致、人机一致”对齐主观评测，靠指标下钻与Rubric二元化降低模糊度；评测是实践科学，靠Good/Bad Case喂养。最后讨论长程Agent（龙虾/爱马仕）带来的变化：从答案评测走向行为评测、从人评主导走向机评主导。

## 要点

- 评测核心目的是回答Agent“好不好、哪里好哪里不好”，为下一轮迭代指明方向。
- 评测对象从单一模型变为“模型+系统+工具+流程”的复杂系统，需覆盖结果、过程、效率、风险四层。
- 观测是评测基石：Agent研发公式为“观测+评测=持续迭代”，Trace系统披露黑盒全路径。
- 评测体系核心不是堆指标而是搭桥，用分层桥梁指标连接模型能力与业务结果。
- 主观评测用“人人一致、人机一致”对齐，通过指标下钻与Rubric二元化降低分歧。
- Agent评测是实践科学：从高频场景少量指标起步，靠Good/Bad Case喂养，Bad Case价值更高。
- 长程Agent推动评测从“答案评测”走向“行为评测”，从人评主导走向机评主导。
- 长程Agent评测基建需具备全链路回放、Case管理、执行沙箱、AI评测引擎、报告归因、回归、门禁等能力。

## 提炼

> 一句话定位：美团图灵团队科普Agent评测：观测为基、搭桥对齐、长程Agent走向行为评测。

### 分节提炼

- **01 评测是什么**：评测核心目的是回答Agent好不好、哪里好哪里不好，为迭代指明方向。；评测对象是“模型+系统+工具+流程”复杂系统，而非单一模型。；评测需覆盖结果、过程、效率、风险四层，只看答案会误判工程价值。；观测是基石：Trace系统披露全路径，隐形动作可观测才能稳定解决。
- **02 核心方法论**：指标体系核心是搭桥：用桥梁指标连接模型能力指标与业务结果指标。；客观评测覆盖高频结构化部分，主观评测覆盖开放性高价值场景，并互相校准。；用“人人一致、人机一致”对齐主观评测，指标下钻+Rubric二元化降低分歧。；评测是实践科学：从少量关键指标起步，靠Good/Bad Case喂养，Bad Case价值更高。；垂域知识语料匮乏时，引入行业专家知识补足模型能力，冷启动阶段尤甚。
- **03 观测评测演进**：短程Agent是Query→Answer，评测重点落在回答本身。；长程Agent要完成复杂任务：多步拆解、多次调用Tool/Skill、动态调整策略。；长程评测从人评主导走向机评主导：人工做标准设计，AI做规模化运行。；评测基建需具备全链路回放、Case管理、执行沙箱、AI评测引擎、报告归因、回归、门禁。
- **04 总结：走向基础设施**：评测对象从“回答”变为“任务系统”，关注能力、稳定性、效率与风险。；评测方法从文本质量评测转向Prompt→Expected Behavior的行为评测。；未来要建设看得见问题、说得清标准、跑得动规模、接得上流程、带得动迭代的体系。；附：开源调研列出pinchbench、claw eval、WildClawBench及Task/Grader/Transcript等术语。

### 带走三句话

1. Agent评测要从“只看结果”转向“结果+过程+效率+风险”四层，否则会误判真实工程价值。
2. 主观评测靠“人人一致、人机一致”：把模糊指标下钻并二元化，用unknown占比反查Rubric。
3. 长程Agent时代要把评测当生产系统来建：回放、Case管理、沙箱、机评、回归、门禁缺一不可。
