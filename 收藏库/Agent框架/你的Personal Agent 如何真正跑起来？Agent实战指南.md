# 你的Personal Agent 如何真正跑起来？Agent实战指南

> 一句话定位：一线实战：把个人分身搭成随时可用、能接续上下文的工作伙伴。

## 摘要

作者结合半年实践，讲清个人分身（Personal Agent）从"想到就聊"到进入日常工作的方法。核心是让它随时可用且能接着上次往下做：把资料、近期工作和记忆接起来，半个想法也能启动讨论，能查则查、能试则试。文中两个案例说明价值：经分团队把数据服务Agent接入WorkBuddy，让使用者无痛调用已建能力，实现"传染机制"；Jev小模型判断群消息，由小模型给候选、分身组织实验、人来校准。搭建经验包括：分层配置提示词（USER/SOUL/操作规则/SOP）、统一记忆路径、用live记录近期状态、保留推导过程与确认状态，防止未定论被当结论。最后介绍"洗澡时刻"——一句prompt让分身主动从积累中发现联系，结论再回实际工作验证。

## 要点

- 个人分身的关键是"随时可用且能接着上次往下做"，把资料、近期工作和记忆接起来，降低重新开始成本。
- 半个想法即可启动：先说给分身听，让它找背景、一起想，能查就查、能试就试、没想完先留下。
- 带动团队有两条路：把方法教给对方，或让对方无痛先用上已建设好的能力，后者需产品支持能力交付与反馈闭环。
- 从想法到实验很快：小模型给候选判断、分身组织实验与检查、人来校准取舍，三个角色各司其职。
- 提示词要分层：背景与当前重点放USER、冲突取舍放SOUL、路径与确认放操作规则、某类任务放SOP/Skill。
- 多设备、多分身要统一记忆路径、维护live近期状态，并注意Session不互通、同步版本不一致的坑。
- 记录要保留推导过程与确认状态，防止"讨论中的推断"被误当成已确认结论。
- "洗澡时刻"用一句prompt让分身从积累中主动发现联系，但结论仍要回实际工作验证。

## 提炼

> 一句话定位：一线实战：把个人分身搭成随时可用、能接续上下文的工作伙伴。

### 分节提炼

- **01 全文**：分身价值在于"随时可用、接着上次往下做"：把背景、资料、近期状态接起来，降低重新开始的成本。；带动他人有两条路：教会方法，或让使用者无痛先调用已建好的能力；产品需支撑能力交付、使用、找人和反馈闭环。；环境建设：资料分稳定背景/当前推进/历史材料，提示词分层为USER/SOUL/操作规则/SOP，多设备统一路径并用live记录近期状态。；"洗澡时刻"等低成本唤起方式让分身主动发现联系，但结论要保留推导过程与确认状态，防止未定论被当成结论。

### 带走三句话

1. 让Agent随时可用、能接续上下文，比单次回答质量更重要——资料、近期状态和记忆要连起来。
2. 配置要分层而非堆规则：USER放背景、SOUL放取舍、操作规则放路径与确认、SOP放任务方法。
3. 所有记录都要标注来源与确认状态，保留推导过程，别把讨论中的推断写成结论。
