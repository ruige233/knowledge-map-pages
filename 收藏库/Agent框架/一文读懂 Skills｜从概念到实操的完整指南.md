# 一文读懂 Skills｜从概念到实操的完整指南

> 一句话定位：Skills：让 Agent 可靠、可控、可复用的“高级技能包”

## 摘要

Skills 由 Anthropic 提出，已成主流 Agent 工具的扩展规范。一个 Skill 是打包成文件夹的“技能包”，内含 SKILL.md 说明书、脚本、资料，封装知识、流程与工具。核心是三级按需加载：元数据始终加载、SKILL.md 匹配时加载、资源按需执行，平衡效果与 Token 成本。调用按意图匹配、读手册、按需执行、反馈结果四步；写好 Skill 需原子性、给例子、立规矩、造接口、勤复盘。相比一次性加载的 Rules，渐进式加载更灵活，缓解规则失效、执行失控、工具迷失。

## 要点

- Skills 由 Anthropic 提出，现已成为多数 Agent 开发工具与 IDE 支持的标准扩展规范。
- 一个 Skill 是文件夹：SKILL.md 说明书 + Script 脚本 + Reference 资料，封装知识与流程。
- 三级加载：元数据始终加载、SKILL.md 触发时加载、资源与脚本按需加载，节省 Token。
- 调用四步：意图匹配、读取手册、按需执行、反馈结果。
- 写好 Skill 五原则：原子性、给例子、立规矩、造接口、勤复盘，其中给例子最关键。
- Skill 按需动态加载优于 Rules 一次性加载，可解决规则失效、执行失控、工具迷失。
- TRAE 支持三种创建方式：设置创建、解析 SKILL.md、对话中让 Skills-creator 创建。
- Description 决定 Skill 能否被正确触发；Skill 擅长确定性流程，不擅长创造力与实时决策。

## 提炼

> 一句话定位：Skills：让 Agent 可靠、可控、可复用的“高级技能包”

### 分节提炼

- **01 Skills 是什么**：Skill 由 Anthropic 提出，已成多数 Agent 工具与 IDE 支持的标准扩展规范。；一个 Skill=文件夹：SKILL.md 说明书+Script 脚本+Reference 资料。；把 Agent 从通才变成特定领域专家的可复用技能包。
- **02 原理与架构**：运行在沙盒环境，可访问文件系统并执行 bash 命令。；三级加载：元数据始终加载、SKILL.md 触发加载、资源按需加载。；脚本代码不进上下文，捆绑大量信息却几乎不增 Token 成本。；与 Command 快捷指令、MCP 原子工具易混淆，可用厨房类比区分。
- **03 调用逻辑**：四步：意图匹配→读取手册→按需执行→反馈结果。；Agent 先扫元数据找匹配 Skill，再读 SKILL.md 细节，按需取用工具。
- **04 与其他概念区别**：Skill 是流程化技能包，与 Command、MCP 定位不同。；用厨房场景类比帮助区分三者价值。
- **05 好 Skill 标准**：以 Good Skills vs Bad Skills 对比说明从能用到好用。；具体好坏对比细节见正文配图与官方博客。
- **06 写作五原则**：五原则：原子性、给例子、立规矩、造接口、勤复盘。；给例子（Few-shot）最关键：直接给出输入输出示例。；立规矩=定角色+拆步骤+画红线，防止幻觉。
- **07 社区资源**：从 Claude 官方 Skills 仓库学习最佳实践。；官方 Skill 可下载或 Git 克隆，放入 Skills 目录重启即识别。
- **08 TRAE 实操**：三种创建方式：设置创建、解析 SKILL.md、对话中让 Skills-creator 创建。；方式二：项目目录新增 .trae/Skills/xxx 导入文件夹即可用。；日常语言描述需求，系统自动匹配调用技能。
- **09 飞书 Spec Coding**：Rules 固定且一次性全量加载，Skill 逐步按需加载更灵活。；以飞书 Spec Coding 演示多角色专家与工具型 Skill 分工协作。；Spec Coding 四阶段：需求分析、技术设计、任务拆解、代码实现。
- **10 总结**：角色型+工具型 Skill 组合，动态加载替代固定规则一次性加载。；多角色分工协作+飞书协作闭环，解决不听话/执行乱/工具少。
- **11 常见问题**：Skill 不生效多半是 Description 没写好，用大白话写清晰。；强模型影响挑技能与定策略；技能本身决定执行下限与稳定性。；Skill 不擅长高创造力、实时动态决策、纯闲聊问答。；社区 Skill 支持 Fork 后二次开发，建议修改复用。
- **12 结语**：Skill 用结构化方法封装知识、流程与工具，让 AI 输出可控可信。；三级加载平衡上下文效率与功能深度，生态丰富降低门槛。

### 带走三句话

1. Skill = SKILL.md + Script + Reference，靠三级加载按需取用、省 Token。
2. 写好 Skill 的关键是给例子：少解释，多给输入输出示例。
3. Skill 擅长确定性流程任务；创造力、实时决策、闲聊交给模型本身。
