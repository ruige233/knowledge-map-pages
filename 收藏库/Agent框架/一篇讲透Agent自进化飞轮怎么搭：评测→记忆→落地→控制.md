# 一篇讲透Agent自进化飞轮怎么搭：评测→记忆→落地→控制

> 一句话定位：评测→记忆→落地→控制四齿飞轮：让Agent把经验变成可验证的改进闭环。

## 摘要

文章针对Agent上线后不积累经验的问题，提出自进化的瓶颈不在单个技术点，而在环节衔接，并提炼出评测→记忆→落地→控制四齿飞轮。核心立场：评测可信度大于系统复杂度；记忆系统核心是治理而非存储。评测承担方向指引、质量门控、经验筛选三重职责；记忆采用策展式写入、分层存储、渐进披露读取；落地走诊断归因到经验沉淀的八环节链路，自动化在前、人工在后；控制上人做教练和裁判，守住五个关键节点，防止对齐漂移。最后给出四条数据通路与四阶段落地路线，强调先跑通最小闭环。

## 要点

- 自进化的瓶颈不是任何单个技术点，而是评测、记忆、Self-Improve 之间的环节衔接。
- 评测可信度大于系统复杂度，失真的评测信号会让 Agent 加速犯错。
- 评测承担方向指引、质量门控、经验筛选三重职责，评完必须做诊断归因。
- 记忆系统的核心是治理而非存储：策展式写入、分层存储、渐进披露读取。
- 落地自动化不等于全自动：八环节链路中关键决策必须有人把关。
- Diff 模式只改局部、可 review、可精准回滚，优于全文重写。
- 异步 Dreaming 巡检跨会话系统性模式，与同步评测互补。
- 四阶段落地路线（最小闭环→半自动→飞轮→元进化），先跑通 Phase 1。

## 提炼

> 一句话定位：评测→记忆→落地→控制四齿飞轮：让Agent把经验变成可验证的改进闭环。

### 分节提炼

- **01 开篇：被拆散的系统**：评测、记忆、Self-Improve 被拆散做，数据通路断裂，飞轮不转。；评测是眼睛、记忆是大脑、Self-Improve 是手脚、人机协作是方向盘和刹车。；自进化的瓶颈不是单个技术点，而是环节之间的衔接。
- **02 概念：自进化三层**：自进化分三层：Artifacts 改产物、Harness 改配套系统、Model 改权重。；Harness 层即时生效、可回滚，是当前投入产出比最高的主战场。；日期格式转换例子：写一条 Skill 即可解决，不必微调模型。
- **03 信号：评测是信号源**：评测三重职责：方向指引、质量门控、经验筛选。；评测集三分法（train/val/test）互不泄漏，防止过拟合刷分。；评测终点不是打分而是诊断归因，归因粒度决定修复精度。；Skill 评测需四层验证：对照实验、难度校准、轨迹追踪、路径验证。
- **04 积累：记忆重在治理**：记忆做不好比没有更差：检索噪声高会迫使团队退回无状态。；写入策展而非全存：正信号触发、失败存为反例、三层晋升。；分层存储加生命周期管理：版本、遗忘、冲突解决、来源溯源。；读取渐进披露：默认只注入顶层，严格 Token 预算。
- **05 落地：八环节工程化**：自动化不等于全自动：候选生成、评测、门控可自动，关键决策要人把关。；八环节链路：诊断归因、信号汇聚、生成候选、独立评测、门控、灰度、回流、沉淀。；Diff 模式只改局部，可 review、可精准回滚。；Dreaming 异步巡检跨会话模式，与同步评测互补。
- **06 控制：人做教练裁判**：人做教练和裁判：分级自主、渐进放权、动态升降级。；五个必须有人的节点：规则级记忆、Skill 确认、回归决策、冷启动、安全边界。；审核疲劳比没有审核更危险，自动门控过滤 95% 低质变体。；对齐漂移靠定期方向性审计、方向性指标、意图对齐评测维度。
- **07 飞轮：四齿咬合**：四条数据通路：评测→记忆、评测→落地、落地→控制→生效、生效→回流评测。；飞轮启动需人工推力：初始评测集、首批 Skill/记忆、安全边界。；持续动力来自失败样本回流、经验晋升 Skill、Dreaming、Auto-Research。；最易跑通场景：真实业务指标反馈加短闭环低延迟。
- **08 收束：三条原则**：三条原则：评测可信度优先、记忆是治理问题、闭环价值在衔接。；自进化是系统设计范式，让每次执行不白费、每次改进经验证。

### 带走三句话

1. 先擦亮评测这双眼睛，再让自动化动起来：评测失真，自动化只会加速犯错。
2. 记忆先治后存：策展式写入、分层存储、渐进披露，治理能力比存储容量重要。
3. 进化要闭环不要孤岛：让评测信号自动流进记忆与 Skill 更新，并回流下一轮评测。
