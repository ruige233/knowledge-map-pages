# AI Agent夺命10连问

> 一句话定位：10道AI Agent面试高频题：从本质、选型到评估的完整梳理

## 摘要

本文梳理 AI Agent 面试 10 道高频考点：Agent 与普通 LLM 的本质区别及循环来源；Workflow/单 Agent/多 Agent 选型；CoT、ReAct、Plan-and-Execute、Self-Refine 四范式；Function Calling 六步流程与参数校验；MCP 与 FC 的正交关系及工具路由；失败容错与防死循环；记忆、知识库、日志区分；上下文溢出与腐化及 KV Cache 优化；RAG 链路与混合检索；Agent 评估与 Pass@k/Pass^k。

## 要点

- AI Agent 与普通 LLM 应用的本质区别在于自主决策、目标驱动与循环闭环，循环源自自回归生成机制。
- 架构选型看两点：路径写得死用 Workflow，写不死上单 Agent，能多出新信息才拆多 Agent。
- CoT 管想、ReAct 加做、Plan-and-Execute 先想全局、Self-Refine 做完再审，生产环境通常混合使用。
- Function Calling 铁律是模型只决策不执行，六步流程由框架代码完成真正调用。
- MCP 与 Function Calling 正交：一个在工具侧标准化接入，一个在模型侧表达调用意图。
- 容错先分解析失败与执行失败，防跑飞靠轮次上限、完成标记、结果校验、人工介入四道防线。
- 记忆、知识库、日志的判据是会不会被语义检索出来影响决策；冲突处理追加优于删除。
- RAG 核心是检索到对的一段：向量+BM25 混合检索、RRF 融合、跨编码器重排；评估用 Pass@k 看能力、Pass^k 看可靠性。

## 提炼

> 一句话定位：10道AI Agent面试高频题：从本质、选型到评估的完整梳理

### 分节提炼

- **01 Agent 本质**：普通 LLM 单轮问答；Agent 是自主决策、目标驱动的循环闭环；循环源于自回归生成机制，只能想一步做一步看一步；所谓变聪明是记忆、工具、流程在积累，模型权重冻结
- **02 三类架构选型**：步骤固定无分支用 Workflow；分支由中间结果决定用单 Agent；拆多 Agent 的前提是产生新信息，否则是烧 token；多 Agent 三种搭法：对等协作、管理者模式、去中心化
- **03 四大推理范式**：CoT 纯推理不碰外部；ReAct 加做与看拿实时数据；Plan-and-Execute 先想全局防短视；Self-Refine 在评审层循环；生产混用：Plan 拆解、ReAct 执行、Refine 把关
- **04 Function Calling 流程**：铁律：模型只做决策，不执行，执行的永远是你的代码；六步：定义函数→传工具说明→发请求→返回 JSON→代码调用→回填结果；Pydantic 一次定义两用：生成 Schema 与参数校验
- **05 MCP 与 FC 关系**：MCP 是标准化工具接入协议，类比工具界 USB-C；FC 在模型侧表达调用意图，MCP 在工具侧统一接入，二者正交；工具规模靠路由控制：分层、按需检索、命名空间
- **06 容错与防循环**：失败分解析失败（执行前）与执行失败（执行后），处理不同；解析失败校验重试兜底；超时指数退避软失败；数据太大先瘦身；防跑飞四道防线：轮次上限、完成标记、结果校验、人工介入
- **07 记忆与知识库区分**：短期记忆是对话窗口；长期记忆存偏好；知识库存公共文档；日志只增不改；判断记忆就一条：会不会被语义检索出来影响下一次决策；冲突处理追加优于删除，删除不可逆
- **08 溢出与腐化**：溢出是装不下，腐化是装得下但找不到，后者不报错更隐蔽；三层方案：治溢出三件套、隔离优于压缩、KV Cache 三铁律；成本是累积的，多项优化节省不能简单相加
- **09 RAG 链路与检索优化**：RAG 是开卷考试，核心是检索到对的一段，离线建库+在线查询；向量管语义、BM25 管字面，RRF 融合排名，跨编码器重排；Agentic RAG 由模型决定查不查、查几轮
- **10 评估与迭代**：任务完成率是硬指标，其余是成本质量护栏；Pass@k 看能力上限，Pass^k 看业务可靠性，有副作用场景只看后者；失败归因归首个错误，并分清 Harness 还是模型

### 带走三句话

1. 先分清 Agent 与普通 LLM：区别在自主决策和闭环，不在组件多少。
2. 选型与防跑飞都靠判据：路径能否写死、拆开有无新信息、检索结果是否影响决策。
3. 评估看场景：有副作用的业务只看 Pass^k 稳定性，别被 Pass@k 的奇迹数字骗了。
