# Build Your Own X

> 一句话定位：一份把"从零实现一门技术"的教程汇总成清单的开源仓库，用动手复刻来替代只读文档式的学习。

## 摘要

由 CodeCrafters 维护，理念取自费曼的"What I cannot create, I do not understand"，按技术主题汇总从零构建的逐步教程，覆盖 3D 渲染器、神经网络与 LLM、区块链与 BitTorrent 客户端、数据库、Git、操作系统、模拟器与虚拟机、容器、处理器、浏览器、Web 服务器、网络协议栈、搜索引擎、游戏与物理引擎、编程语言、文本编辑器等方向。教程以 C、C++、Rust、Go、Python、JavaScript、TypeScript、Haskell 等多语言实现，同一技术常有多个语言版本，每个条目都是可运行项目而非纯理论。截至 2026-10-02 约 551k stars、51.7k forks，适合作为系统方向自学路线索引。

## 要点

- 按主题聚合而非按语言组织：同一技术（如数据库、Web 服务器、区块链）在多个语言下有并列教程，便于横向对比实现差异。
- 典型入口包括 C 版 "Let's Build a Simple Database"、Rust 版 "Writing an OS in Rust"、Python 版 "Let's Build A Simple Interpreter" 与 LLM / 扩散模型 / RAG 的 Python 实现。
- 覆盖层次从渲染与游戏物理一路延伸到编译器、操作系统、容器和处理器，可作为 CS 核心课程的动手补充路径。
- 关注度：约 551k stars、51.7k forks；仓库创建于 2018-05-09，最后推送 2026-07-14；GitHub topics 为 awesome-list、free、programming、tutorial-code、tutorial-exercises、tutorials。
- 维护方 CodeCrafters 另提供交互式编程挑战站点，与本清单互为补充。

## 关联

- 与 `教程/Dive-Into-LLMs.md` 互补：后者偏大模型原理与实战讲解，本条目偏"自己实现一个 X"的项目式路径。
- 与 `教程/Learn-Claude-Code.md`、`教程/Claude-Code-Best-Practice.md` 同属教程类，但面向底层系统与语言实现，而非 AI 工具用法。
