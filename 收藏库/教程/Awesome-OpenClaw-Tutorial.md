# Awesome OpenClaw Tutorial

> 一句话定位：一本面向中文用户的开源 OpenClaw 实战教程，把安装部署、配置优化、Skills 扩展与实战案例串成从零到"超级个体"的学习路径。

## 摘要

这份中文 OpenClaw 教程对应清华大学出版社的纸质书《OpenClaw 超级个体实操手册》，GitHub 版持续更新。15 章按四段组织：零基础入门（认识 OpenClaw、快速部署、发出第一条消息）、核心功能实战（文件管理、知识库、日程管理、自动化）、进阶技能（Skills 扩展、多平台集成、API 接入、高级配置）、实战案例（五类人群场景、高级自动化与超级个体工作流）。部署部分并列对比飞书妙搭、宝塔面板、JVSClaw、Kimi Claw、腾讯 WorkBuddy 等方案便于选型，并覆盖 1800+ Skills 扩展与飞书、企微、钉钉、QQ、微信集成。截至 2026-10-02 约 4.57k stars、680 forks。

## 要点

- 结构清晰的四阶段路径：入门 → 核心功能 → 进阶技能 → 实战案例，可按人群直接跳读对应章节。
- 部署方案以对比形式给出，包含飞书妙搭、宝塔面板、JVSClaw、Kimi Claw、腾讯 WorkBuddy、扣子 OpenClaw 等，覆盖个人与企业不同安全需求。
- 强调 1800+ Skills 扩展与多平台消息集成（飞书/企微/钉钉/QQ/微信），是中文生态里整合度较高的资料。
- 维护了版本变更记录：v2026.3.12 的 Control UI 重设计与 Kubernetes 支持、v2026.3.13 的 Chrome DevTools MCP attach 模式与 Ollama 一键安装、v2026.3.24 的 Node.js 版本要求提升与多平台稳定性修复。
- 关注度：约 4.57k stars、680 forks；主语言 Shell，GitHub topics 为 openclaw、openclaw-skills；许可证为 NOASSERTION（自定义，未标准化）。
