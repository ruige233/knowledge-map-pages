# Easy-Vibe

> 一句话定位：Datawhale 出品的「会说话就能编程」课程，从产品原型到全栈交付再到 Claude Code 高级工作流，分三个阶段递进。

## 摘要

Datawhale China 推出的 AI 时代产品构建课程，主张「会说话就能编程」：先说清想要什么，再把它变成真实产品。学习路径分四层——快速入门先建立 vibe coding 的第一印象；阶段一把想法做成可演示的原型；阶段二做端到端全栈交付，收敛到 AI 文案生成 SaaS 与在线考试系统两个大项目，串起 Supabase 数据库、后端 API、Zeabur 部署与 Stripe 支付；阶段三进入 AI 原生开发，覆盖 Claude Code、MCP、Skills、Agent Teams、长时任务、Spec Coding 与十余个跨平台项目。附录知识库含 9 大领域、80+ 互动主题，教程支持 10 种语言，并提供 `llms.txt` 方便编码智能体定位内容。README 标注 CC BY-NC-SA 4.0 许可。

## 要点

- **四层学习路径**：快速入门（人人可做）→ 阶段一产品原型 → 阶段二全栈交付 → 阶段三 AI 原生开发，另有附录知识库兜底概念缺口。
- **阶段二靠两个大项目串联技术栈**：AI 文案生成 SaaS（登录、生成、计费、后台管理）与在线考试系统，配套前端工作流、设计转代码、Supabase、后端 API、Zeabur 部署与 Stripe 计费。
- **阶段三与编码智能体工作流深度绑定**：Claude Code 基础、MCP、Skills、长时任务、Agent Teams、Superpowers（TDD 与工程规范）、Claude Agent SDK、从 vibe coding 到 spec coding，再加 11 个跨平台项目（微信小程序、Android/iOS、PWA、浏览器扩展、Electron、VS Code 扩展、Qt 工业 HMI、NFT 等）。
- **对智能体友好**：仓库提供 `llms.txt`，让 OpenClaw、Claude、Cursor、Trae 等助手快速理解仓库结构并找到对应教程。
- **附录与可读性**：9 大知识领域、80+ 互动主题，含双钻模型、Jobs to Be Done、The Mom Test 等需求验证方法，用动画与交互组件降低概念门槛。
- **元数据**：API 快照约 19,603 stars、1,874 forks；仓库创建于 2025-12-28，主语言 JavaScript。
