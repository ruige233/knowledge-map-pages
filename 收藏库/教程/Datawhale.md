# Datawhale

> 一句话定位：成立于 2018 年的中文 AI 开源学习社区组织主页，是它 223 个仓库（LLM、智能体、具身智能、机器学习教程）的总入口。

## 摘要

Datawhale 是 2018 年 12 月成立的中文 AI 开源组织，价值观为「for the learner，和学习者一起成长」，GitHub 组织现有 33.9k 关注者、223 个公开仓库，官网为 datawhale.cn。组织 profile README 的 Trending 区块固定展示 16 个项目，覆盖大模型学习全链路：hello-agents（82.5k stars）、happy-llm（34.3k）、self-llm（32.4k）、easy-vibe（19.7k）、all-in-rag（11.9k）、vibe-vibe（6.1k）、tiny-universe（5.1k）、every-embodied（4.0k）等；仓库页另有不在 Trending 里的高星教程 pumpkin-book（26.1k，西瓜书公式详解）与 llm-cookbook（24.8k，吴恩达课程中文版）。README 同时提供《人工智能培养方案》《开源指南》《开源机遇清单》三份学习与贡献导航。近期提交集中在具身智能与机器人、LLM 算法与系统（CUDA/Triton）、世界模型、推理部署四个方向。
