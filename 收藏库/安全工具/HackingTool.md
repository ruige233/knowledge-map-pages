# HackingTool

> 一句话定位：一个用 Python 写的一体化安全工具集合，把 185 个以上开源攻防工具按 20 多个类别收进统一的交互式菜单，靠关键词搜索和批量安装省去逐个配置的麻烦。

## 摘要

HackingTool 是面向渗透测试与安全研究的一体化工具集合，主语言 Python，把 185 个以上开源安全工具按 20 多个类别组织进统一的交互式命令行菜单，覆盖信息收集、SQL 注入、XSS、钓鱼攻击、无线攻击、后渗透、取证、逆向工程，以及新增的 Active Directory、云安全和移动安全。它提供智能搜索，输入关键词或自然语言描述即可定位工具；每类工具支持批量安装（分类菜单输入 97），并提供一行命令安装与 Docker 部署。项目采用 MIT 许可，仓库创建于 2020-04-11，快照时约 8.0 万 star、9,079 fork。

## 要点

- **规模与覆盖**：185+ 工具、20+ 大类，近期新增 35 个工具以及 Active Directory、Cloud Security、Mobile Security 三个分类。
- **检索与安装效率**：支持关键词 / 自然语言搜索定位工具；分类内输入 97 可批量安装该类全部工具；另有一行命令安装与 Docker 部署两种落地方式。
- **能力范围**：信息收集、SQL 注入、XSS、钓鱼攻击、无线攻击、后渗透、取证、逆向工程、云安全、移动安全、Active Directory —— 覆盖渗透测试从侦察到后渗透的主要阶段。
- **技术栈与维护状态**：Python 编写，MIT 许可，约 80,030 star、9,079 fork，仓库创建于 2020-04-11，最后推送 2026-08-23，仍在持续更新。
- **使用边界**：工具集面向已获授权的渗透测试、CTF 与教学场景，工具本身不附带授权，滥用属于违法行为。
- **与同类的关系**：它是「工具集合 / 安装器」而非单一工具，价值在于分类索引与批量部署，具体能力取决于其收录的上游项目。
