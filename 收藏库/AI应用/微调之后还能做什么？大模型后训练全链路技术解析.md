# 微调之后还能做什么？大模型后训练全链路技术解析

> 一句话定位：一文梳理大模型后训练全链路：微调、对齐到推理优化。

## 摘要

本文系统梳理大模型后训练全链路。后训练是在预训练模型上针对特定任务做额外训练，核心是微调与对齐。预训练扩展律边际收益递减，基于强化学习的后训练与推理期扩展成为新增长维度；以 Llama 3 为例说明偏好数据、拒绝采样、SFT、DPO 对齐的飞轮迭代。微调分全量微调与参数高效微调，LoRA 以低秩分解减少更新参数；对齐涉及偏好标签、奖励模型与 PPO/DPO/GRPO 策略优化。推理阶段从快思考转向慢思考，SFT 偏记忆、RL 偏泛化，DeepSeek R1 证明仅强化学习也能取得强推理。

## 要点

- 后训练指在预训练模型上针对特定任务或数据做额外训练，核心是微调（Fine-tuning）与对齐（Alignment）。
- 预训练扩展律边际收益递减，后训练扩展律与 Test-time scaling 成为新的性能提升维度。
- Llama 3 示例的飞轮流程：生成偏好对、拒绝采样选 SFT 数据、SFT 训练、DPO 对齐，迭代优化。
- SFT 数据由采样模型多次生成回复、RM 选优；偏好数据有四级等级，且 edited > chosen > rejected。
- 微调分全量微调（FFT）与参数高效微调（PEFT），LoRA 用低秩矩阵 A、B 分解权重 W，只更新少量参数。
- PPO 依赖奖励信号并限制更新幅度；DPO 免奖励模型直接优化偏好；GRPO 以组内平均奖励替代价值模型。
- 奖励模型优化思路含 LLM-as-judge、Generative RM、Critic Model，并从 ORM 走向更细粒度的 PRM。
- 推理阶段从快思考转向慢思考，方法有 CoT、MCTS、STaR、Quiet-STaR；SFT 偏记忆、RL 偏泛化。

## 提炼

### 分节提炼

- **01 飞轮迭代优化**：后训练是飞轮：偏好数据、拒绝采样、SFT、对齐反复迭代，让模型更强。；每轮用当前最优模型采样并选优，训出 SFT 模型后再做 DPO 对齐。
- **02 偏好标签数据**：偏好标签数据形如 <input,accept,reject> 三元组。；人类偏好反馈是 RLHF 对齐训练的标签来源。
- **03 奖励模型**：奖励模型输出奖励信号，分 Rule-based RM 与 Model-based RM。；RM 用于拒绝采样打分，也为强化学习提供奖励信号。
- **04 策略优化算法**：策略优化算法有 DPO、PPO、GRPO 三种常见选择。；DPO 免奖励模型、PPO 限制更新幅度、GRPO 用组内平均奖励替代价值模型。

### 带走三句话

1. 后训练要把 SFT 与 RL 对齐做成飞轮：选优数据训练，再让奖励模型引导策略优化。
2. RL 负责泛化、SFT 负责稳定输出格式与记忆，二者缺一不可。
3. 推理期用慢思考（CoT、MCTS、STaR）与更细粒度 PRM，是后训练之后的又一性能杠杆。
