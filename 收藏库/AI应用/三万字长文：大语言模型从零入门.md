# 三万字长文：大语言模型从零入门

> 一句话定位：从预测下一个 token 到 ChatGPT：一条线讲清大语言模型原理

## 摘要

本文用猜数字游戏和“他口渴了，于是喝了一杯____”贯穿，讲清大语言模型。语言模型是给定前文、预测下一个 token 概率分布的程序；预测越准越接近通过图灵测试，也越能把文本压缩到接近语言的熵。实现靠神经网络：加权求和+ReLU 逼近任意函数，梯度下降与反向传播调参，归一化与残差让深层可训练。核心结构是 Transformer：嵌入、注意力与前馈网络。基座模型只会续写，经 SFT、RLHF、推理强化学习变成聊天助手；联网、看图本质都是变成 token。能力随规模提升，仍有幻觉、知识截止等局限。

## 要点

- 语言模型是给定前文、输出“下一个 token 概率分布”的程序，逐 token 循环即可生成整段话。
- 衡量预测好坏用交叉熵，它永远不低于语言的熵；预测越准=压缩越短=越接近智能。
- 神经网络用“加权求和+ReLU 弯折”逼近任意函数，梯度下降与反向传播调参。
- 归一化和残差连接解决梯度消失/爆炸，让几十上百层的深网络能稳定训练。
- Transformer=嵌入+多头注意力+前馈网络：注意力收集上下文，前馈网络加工信息。
- 预训练得到只会续写的基座模型，SFT、RLHF、推理强化学习把它变成聊天助手。
- 工具调用、看图本质都是把一切变成 token，Agent 即模型与外部程序的循环。
- 能力随规模按幂律提升但降不到零，仍存在幻觉、知识截止、上下文有限等局限。

## 提炼

> 一句话定位：从预测下一个 token 到 ChatGPT：一条线讲清大语言模型原理

### 分节提炼

- **01 本质与度量**：语言模型=给定前文输出下一个 token 概率分布；token 是切分单位，逐 token 循环生成；预测极准即通过图灵测试；文字里藏着知识、逻辑、常识；信息量 I=-log2p，熵是平均不确定性，也是无损压缩的极限；交叉熵是训练损失且永不低于熵；香农估算英文每字符熵约 0.6～1.3 bit
- **02 神经网络**：神经元=加权求和+ReLU 弯折；Softmax 把分数变成概率；通用逼近定理保证表达能力，深度让表达能力指数增长；梯度下降调参；Softmax+交叉熵的梯度=预测−答案，反向传播正反一遍算全部梯度；归一化稳数值、残差连接给梯度直通路；用验证集判断过拟合与泛化
- **03 Transformer 结构**：嵌入把 token 编号换成向量，训练让含义相近的向量靠近；注意力用 Q·K 打分、Softmax 加权平均 V，让位置有选择地收集前文信息；因果掩码只许往前看；多头注意力并行捕捉多种关系，RoPE 编码相对位置；前馈网络占参数约三分之二，负责“加权求和+弯折”的复杂变换
- **04 从模型到 ChatGPT**：自回归生成逐 token 接龙，已写的 token 不会撤回；贪心/Top-p 与温度决定怎么挑；基座模型只会续写；SFT 学格式，RLHF/DPO 学偏好，推理强化学习练推理；工具调用与看图都是把一切变成 token，外部程序执行后拼回上下文；规模定律：交叉熵随规模按幂律下降但降不到零；幻觉源于目标“像”非“真”等
- **05 总结**：主线：预测下一个 token→交叉熵→Transformer→后训练→局限；大多数局限都能从“预测下一个 token”这一目标找到根源

### 带走三句话

1. 大语言模型只做一件事：给定前文预测下一个 token，智能来自把这件事做到极致。
2. 预测得准不准看交叉熵，它逼近的是语言的熵，也就是压缩的极限。
3. 模型的核心是 Transformer 加规模与后训练，局限多源于“预测下一个 token”本身。
