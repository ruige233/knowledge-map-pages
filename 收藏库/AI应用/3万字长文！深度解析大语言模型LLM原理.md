# 3万字长文！深度解析大语言模型LLM原理

> 一句话定位：从数学原理到GPU集群，拆解大语言模型训练全流程

## 摘要

本文以工程视角拆解大语言模型原理：大模型即超大参数模型，Transformer 以多头注意力替代 RNN/LSTM 顺序处理，预训练需构造最大上下文以提升推理精度。接着梳理神经网络发展史、词向量与 BPE 分词，介绍预训练、SFT 与 RLHF 三阶段。再推演前馈传播：从 MLP、四种激活函数到矩阵化计算，详解位置编码、self-attention 的 Q/K/V 计算、FFN 与残差连接。然后讲解反向传播：以链式法则逐层求偏微分，配合梯度下降与自适应学习率更新参数。最后说明为何需要超大集群，介绍四种并行方式与 GPipe、PipeDream、ZeRO、混合精度等优化手段。

## 要点

- 大模型即超大参数模型；Transformer 用编码器-解码器堆叠与多头注意力计算 token 关联度，替代 RNN/LSTM 的顺序处理。
- 训练三阶段：预训练（无监督）→ SFT 有监督微调 → RLHF 基于人类反馈强化学习。
- 文本先经 subword 分词（BPE，约 0.75 词/token）转为向量，再送入网络计算。
- 前馈传播是矩阵乘加与激活函数：z=a·W+b、a=σ(z)，可拆分为 GPU 并行计算。
- self-attention 用 Wq/Wk/Wv 算注意力分数，softmax 归一后与 V 加权求和得到输出。
- 反向传播基于链式法则逐层求权重偏微分，再以随机梯度下降沿负梯度更新参数。
- 学习率过大跳过最小值、过小收敛慢；AdaGrad 按迭代次数自适应缩小学习率。
- 单卡不够用，需数据/模型/流水线/张量并行，配合激活重计算、混合精度与 ZeRO 优化。

### 分节提炼

- **01 LLM总览**：“大模型”泛指“超大参数模型”，参数含神经元数量、层数、权重、偏移量、超参数。；Transformer用编码器-解码器堆叠与多头注意力（MHA）计算前后token关联度。；RNN/LSTM靠门机制按时间赋予token不同重要性，与Transformer区别巨大。；预训练时构造“同一时间可看见的最大上下文”可提升推理精准度，故需超大规模集群。
- **02 预训练概览**：神经网络史节点：BP算法、隐单元、CNN、GPU跑AlexNet、AlphaGo强化学习。；2017年Transformer放弃循环层仅依赖注意力，并行化带来训练速度极大提升。；词向量从one-hot演进到word embedding，BPE子词分词约0.75词/token。；训练三阶段：Pre-Train预训练→SFT有监督微调→RLHF基于人类反馈强化学习。
- **03 前馈传播演算**：激活函数引入非线性；分类用交叉熵损失，回归用L1/L2损失。；前馈传播可化为 zL=aL-1*WL+bL 与 aL=σ(zL) 的矩阵乘加与激活计算。；self-attention用Wq/Wk/Wv计算注意力分数并加权求和得到输出。；FFN为两层线性变换夹ReLU；残差连接 LayerNorm(x+Sublayer(x)) 抑制梯度消失。
- **04 反向传播与梯度下降**：反向传播以每层权重为变量计算损失函数梯度，核心是链式法则逐层回传。；∂C/∂w=∂C/∂z*∂z/∂w，需递归向最后一层求解才能得到所有偏微分。；梯度下降沿负梯度方向迭代；学习率太大跳过最小值、太小收敛慢。；AdaGrad为每个参数设置自适应学习率，迭代越多学习率越小。
- **05 为何需要超大集群**：训练本质：预测token→算Loss→反向传播求梯度→梯度下降刷新参数直到收敛。；参数规模与训练上下文规模决定需要超大集群支撑。
- **06 GPU并行训练**：并行形式：数据并行、模型并行、流水线并行、张量并行。；GPipe空等约42%；PipeDream打破批次限制交替执行FP/BP。；张量并行水平切分GEMM与QKV计算，拆分计算后再合并。；优化手段：激活重计算、混合精度FP16/FP32、ZeRO内存优化。
- **07 参考文献**：重点参考Lilian Weng并行训练博客、李宏毅Transformer讲义、GPT的RLHF论文。；涵盖GPipe/PipeDream/ZeRO/混合精度/Adafactor等主题文献。

### 带走三句话

1. Transformer 的精髓是用多头注意力并行计算 token 关联度，替代 RNN 的顺序处理。
2. 训练闭环：前馈预测、损失求差、反向传播求梯度、梯度下降更新参数，循环至收敛。
3. 单卡算力与显存不够，大模型靠数据/模型/流水线/张量并行加混合精度与 ZeRO 提效。
