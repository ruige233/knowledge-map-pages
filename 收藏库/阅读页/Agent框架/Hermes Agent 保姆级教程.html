Hermes Agent 最近火得不行，GitHub 已经快 9 万 Star 了。它其实就是一个更高级的 OpenClaw，更稳定、更省钱，而且会自己进化，越用越聪明。

之前有不少人靠帮别人装 OpenClaw 赚到了钱，现在Hermes刚刚起步，咸鱼已经有人开始做了，早就是优势。

Hermes 的中文教程目前还不多，所以我把从安装到实战再到变现的全流程整理了一份。不管你是自己用还是拿去接单，这一篇都够了。

01新手入门

本节提炼
  • macOS/Linux/WSL2 用一行 curl 命令安装，Windows 需先装 WSL2。
  • 安装会自动处理 Python、Node.js、Git 依赖并创建 ~/.hermes/ 配置目录。
  • 新手选 Quick Setup，模型可用 DeepSeek、Kimi 或 OpenRouter 免费模型。
  • 常用命令：hermes、hermes model/tools/gateway/setup/doctor、hermes migrate openclaw。

目标很简单，把 Hermes 跑起来，完成第一次对话。

macOS / Linux / WSL2 一行命令搞定。

  • curl-fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh |bash

Windows 用户需要先装 WSL2，然后在 WSL2 终端里执行上面的命令。

安装过程会自动处理 Python、Node.js、Git 这些依赖，还会创建 ~/.hermes/ 配置目录。装完跑两个命令确认一下。

hermes version

hermes doctor

模型配置

系统会自动进入配置向导，选 Quick Setup 就行。模型供应商推荐新手先选 DeepSeek 或者 Kimi，或者直接使用 OpenRouter 里面的免费模型，免费额度高，等熟了再换高阶模型。

  • hermes model

配好之后测试一下。

  • hermes chat -q"Hello! What tools do you have available?"

回复正常就说明装好了。

常用命令

后面会反复用到，先混个眼熟。

命令用途
hermes开启对话
hermes model选择模型
hermes tools配置工具
hermes gateway启动消息网关
hermes setup重新配置
hermes doctor诊断问题
hermes migrate openclaw从 OpenClaw 迁移

到这里你的 Hermes 就能正常跑了。接下来才是拉开差距的地方。

02进阶配置

本节提炼
  • 任务拆成 8 个模块可单独配模型，核心模块用强模型、杂活用免费模型。
  • 作者调完 token 费用省了六七成，效果基本没打折扣。
  • SOUL.md 定义人格，可手写或让 Hermes 根据对话自动生成。
  • 接入飞书/Telegram 走 hermes gateway setup 或改 config.yaml。

目标是让 Hermes 从"能用"变成"好用"。这个阶段做完，体验会和新手阶段完全不一样。

模型分模块配置

这是很多人忽略的地方，也是 Hermes 设计得最聪明的地方。

它把任务拆成了 8 个模块，每个模块可以单独配模型。做过后端的同学应该秒懂，不同模块对"智力"的要求不一样，没必要全挂最贵的。

记忆总结、技能创建这些核心模块，配 Claude Opus 或者 GPT-4o。网页搜索、简单文本处理这些脏活累活，用 OpenRouter 免费模型就行。OpenRouter 里面免费模型一大堆，我自己调完之后 token 费用省了六七成，效果基本没打折扣。

SOUL.md

SOUL.md 是 Hermes 的人格文件，位置在 ~/.hermes/SOUL.md。你是谁、说话风格、做事偏好、遇到问题先干啥，全定义在这里。不写这个文件，Hermes 就是个通用 Agent，写好了才是真正懂你的 Agent。差别是质的。

两种写法。

手动写，直接编辑 ~/.hermes/SOUL.md，把你的身份、工作习惯、沟通偏好写进去。比如你喜欢先看数据再做决定，比如你习惯用中文交流，比如你是做后端开发的，这些都可以写。

让它自己学，先跟 Hermes 正常聊一段时间，聊完之后说一句"根据我们的对话调整 SOUL.md"。它会自动总结你的偏好写进去。因为你一直在纠正它，它反而比你自己更清楚你要什么。

写好之后可以 cat ~/.hermes/SOUL.md 看看它总结了什么，不满意就继续调。

记忆系统

记忆系统由 5 个文件组成，搞明白各自分工就够了。

  • SOUL.md ，人格定义，你自己写
  • user.md ，它对你的长期观察，自动写入
  • memory.md ，事件记忆，每次对话注入上下文
  • skills/ ，固化的可复用流程，越用越丰富
  • state.db ，聊天记录底层存储

只有 SOUL.md 需要你操心，其他四个它自己处理。

验证记忆是否正常也简单。告诉它你的名字和偏好，退出对话，重新 hermes chat，问它"你知道我是谁吗？"。能记住就说明记忆系统跑通了。

接入通讯平台

Hermes 支持 15+ 通讯平台，接好之后它就是一个 24 小时在线的助理。

以飞书为例，国内使用方便

最方便的方式是跑交互式配置向导。

  • hermes gateway setup

选择飞书，按指引填入 App ID 和 App Secret。需要先去飞书开放平台（open.feishu.cn）创建一个企业自建应用，开启机器人能力，拿到这两个凭证。

也可以手动编辑 ~/.hermes/config.yaml。

  • gateway:
  • adapters:
  • feishu:
  • enabled:true
  • require_mention:false
  • default_group_policy: open

配好之后启动网关。

  • hermes gateway

在飞书里给机器人发条消息，能回复就说明接通了。

Telegram配置

在 Telegram 搜 @BotFather，发 /newbot 创建机器人拿到 Token，然后配置。

  • hermes config set TELEGRAM_BOT_TOKEN your-bot-token
  • gateway:
  • adapters:
  • telegram:
  • enabled:true

同样 hermes gateway 启动就行。

03高级玩法

本节提炼
  • Skill 系统是 Hermes 与 OpenClaw 最本质的区别，完成任务自动沉淀经验。
  • 触发建技能：完成多步骤任务后、主动说创建技能、跨会话重复工作模式。
  • 定时任务编辑 ~/.hermes/cron/tasks.yaml，用 Cron 调度并推送到平台。
  • hermes doctor 定位问题，hermes migrate openclaw 一键迁移。
  • hermes: command not found 时执行 source ~/.bashrc。
  • 模型不响应先检查 API Key 额度。

目标是让 Hermes 自己进化，跑自动化任务。

Skill 系统

这是 Hermes 跟 OpenClaw 最本质的区别。

当 Hermes 完成一个复杂任务后，它会自动把经验沉淀成可复用的 Skill。下次遇到类似的事，它不是从零开始，而是直接调用之前的经验。你用得越多，它积累的 Skill 就越丰富，干活也越高效。

触发 Skill 创建的时机，完成多步骤任务后、你主动说"创建技能"、或者跨会话重复某种工作模式。

  • ls ~/.hermes/skills/

可以试试让它干个复杂活感受一下。

  • hermes chat
  • > 请帮我抓取 Hacker News 首页的AI新闻，并总结成中文摘要

观察它完成后是不是会提示创建新技能。

定时任务

内置 Cron 调度，编辑 ~/.hermes/cron/tasks.yaml 就能配。

  • tasks:
  • -name: daily_news
  • schedule:"0 9 * * *"
  • command:"总结今日AI新闻"
  • platform: telegram
  • chat_id:"your-chat-id"

配好之后它每天早上 9 点自动执行，结果发到你的通讯平台。不用一直盯着，后台自己跑。

排错和迁移

跑一遍 hermes doctor，配置错误、模型连接、权限问题，基本都能定位。

从 OpenClaw 搬家也简单，一条命令。

  • hermes migrate openclaw

技能、记忆、配置一次性带走，全选 Yes，两三分钟搞定。

05变现

本节提炼
  • 四种变现：代安装、垂直行业定制、卖 Skill 包、让 Agent 跑自动化业务。
  • 行业定制客单价高于代安装；Skill 是 Markdown 文件，交付成本低。
  • 核心竞争力是对 Hermes 的理解深度，先玩透先吃红利。

这块我觉得值得聊聊。之前 OpenClaw 火的时候，有不少人靠帮别人安装配置在闲鱼上赚到了钱。Hermes 现在中文教程还不多，机会窗口还在。

代安装服务，在闲鱼、小红书上挂安装配置服务。很多人不会折腾命令行，愿意花钱买省心。你看完这篇教程，基本就能接单了。

垂直行业定制，针对具体行业配好 Skill 和工作流。比如帮电商团队配一个自动写商品描述的 Agent，帮自媒体团队配一个自动追热点写稿的 Agent。这个客单价比代安装高得多。

卖 Skill 技能包，把调好的 Skill 打包卖。比如"小红书运营 Skill 包"、"客服自动回复 Skill 包"。Skill 文件本身就是 Markdown，交付成本很低。

让 Agent 跑自动化业务，配好定时任务，让它自动采集信息、生成内容、发布到平台。调试成本不低，但跑通了就是被动收入。

说个现实的问题，这些变现方式门槛都不算高，核心竞争力是你对 Hermes 的理解深度。闷声发大财这事，谁先玩透谁先吃到红利。
