01FileZilla FTP 工具

本节提炼
  • 免费开源，分为客户端与服务器两个版本。
  • 客户端支持 FTP、FTPS、SFTP，界面有条理、便于管理多站点。
  • 服务器版小巧可靠，支持 FTP 与 SFTP。

FileZilla是一个免费开源的FTP软件，分为客户端版本和服务器版本，具备所有的FTP软件功能。可控性、有条理的界面和管理多站点的简化方式使得Filezilla客户端版成为一个方便高效的FTP客户端工具，而FileZilla Server则是一个小巧并且可靠的支持FTP&SFTP的FTP服务器软件。

FileZilla 不仅支持 FTP，还支持 FTP over TLS (FTPS) 和 SFTP 。

02百灵快传 B0Pass

本节提炼
  • 基于 Go 语言，定位手机电脑超大文件传输与局域网共享。
  • 电脑双击执行、手机扫码即可双向传输大文件。

百灵快传（B0Pass）是一款基于 Go 语言的高性能 “手机电脑超大文件传输神器”、“局域网共享文件服务器”。

img

了解更多：https://www.oschina.net/p/b0pass

03LFTP 命令行工具

本节提炼
  • 类 Unix 命令行 FTP 客户端，GPL 发布。
  • 除 FTP 外支持 FTPS、HTTP、HTTPS、SFTP、FXP，并内置 BitTorrent 客户端。

lftp是一款类 Unix 系统下命令行界面的 FTP 客户端软件，作者是 Alexander Lukyanov ，在 GNU通用公共许可证下发布。除了 FTP 外，还支持 FTPS 、 HTTP 、 HTTPS 、 SFTP 、 FXP 等多种协议。此外， lftp 也内含一个简单的 BitTorrent 客户端。

04普通用户登录

本节提炼
  • lftp tom@192.168.1.17 以普通用户登录，随后输口令。
  • 进入交互提示符后用 ls 列出远端目录。
  • [root@gaosh-17 ~]# lftp tom@192.168.1.17
  • 口令:
  • lftp tom@192.168.1.17:~> ls
  • drwxr-xr-x 2 1001 1001 6 Jul 17 13:46 tom-test
  • lftp tom@192.168.1.17:~>

05下载与上传

本节提炼
  • mget -c 文件名可下载，-c 表示断点续传。
  • put 文件名把本地文件上传到远端目录。
  • [root@gaosh-64 ~]# mkdir pgtest
  • [root@gaosh-64 ~]# cd pgtest/
  • [root@gaosh-64 pgtest]# touch aaa
  • [root@gaosh-64 pgtest]# lftp 192.168.1.17
  • lftp 192.168.1.17:~> cd pub/
  • lftp 192.168.1.17:/pub> ls
  • -rw-r--r-- 1 14 50 2523 Jul 18 05:33 CentOS-Base.repo
  • lftp 192.168.1.17:/pub> mget -c CentOS-Base.repo
  • 2523 bytes transferred
  • [root@gaosh-64 pgtest]# lftp 192.168.1.17
  • lftp 192.168.1.17:~> ls
  • drwxrwxrwx 2 0 0 6 Jul 18 07:20 pgtest
  • dr-xr-xr-x 2 0 0 30 Jul 18 05:43 pub
  • lftp 192.168.1.17:/> cd pgtest/
  • lftp 192.168.1.17:/pgtest> put aaa
  • lftp 192.168.1.17:/pgtest> ls
  • -rw------- 1 14 50 0 Jul 18 07:21 aaa

了解更多：https://www.oschina.net/p/lftp

06trzsz.js

本节提炼
  • trzsz（trz/tsz）兼容 tmux，类似 lrzsz（rz/sz）。
  • 有进度条，支持目录传输与拖动上传。

trzsz (trz /tsz) 是一个兼容 tmux 的文件传输工具，和 lrzsz ( rz /sz ) 类似，并且有进度条，支持目录传输，支持拖动上传。

08NitroShare 局域网

本节提炼
  • 基于 Qt，支持 Windows、OS X 与 Linux。
  • 自动发现局域网设备，界面直观，可传输整个目录。

NitroShare 是一个局域网文件传输工具，支持 Windows、OS X 和 Linux，基于 Qt 开发。

特点：支持跨平台、自动发现局域网的设备、简单直观的用户界面、可传输整个目录

11OnionShare 匿名分享

本节提炼
  • 开源工具，可安全匿名共享任意大小文件。
  • 启动 Web 服务器作为 Tor onion 服务，生成临时 URL。
  • 文件托管本机，对方用 Tor 浏览器访问下载。

OnionShare 是一个开源工具，可以让你安全和匿名地共享任何大小的文件。

它通过启动一个 Web 服务器工作，作为 Tor onion 服务被访问，并生成一个临时的 URL 以访问和下载文件。将文件托管到自己的电脑，并使用 Tor onion 服务，使其可以通过互联网临时访问。其他用户只需要使用 Tor 浏览器从你的主机下载文件即可。

12croc 跨平台

本节提炼
  • 任意两台电脑间简单安全传输文件与文件夹。
  • 端到端加密、多文件传输、支持中断恢复。
  • 无需本地服务器或端口转发。

croc 是一种允许任意两台计算机简单安全地传输文件和文件夹的工具。

它提供端到端加密、允许多个文件传输、允许恢复被中断的传输，同时不需要本地服务器或端口转发。

了解更多：https://www.oschina.net/p/croc

13tl-rtc-file

本节提炼
  • 使用 WebRTC 在 web 端 P2P 点对点传输。
  • 分片传输、跨终端、不限平台、内网不限速，支持私有部署与二次开发。

tl-rtc-file 使用 webrtc 在 web 端传输文件，支持传输超大文件，P2P 点对点传输。

优点 ：分片传输，跨终端，不限平台，方便使用，内网不限速，支持私有部署，代码简单，通俗易懂，可二次开发，可作入门学习。
