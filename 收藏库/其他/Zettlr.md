# Zettlr

> 一句话定位：一个本地优先的跨平台 Markdown 写作与出版工具，把学术论文写作、引用管理和 Zettelkasten 式笔记放进同一个编辑器。

## 摘要

Zettlr 是基于 Electron、Vue 3 与 TypeScript 的跨平台 Markdown 写作与出版工具，把学术写作和知识管理放进同一个本地优先的编辑器。笔记以纯文本文件保存在本地磁盘，支持 Zettelkasten 式链接、标签与全文检索，并集成 Zotero、JabRef 等文献管理器插入引用。导出链路依赖 Pandoc 与 LaTeX，可生成 PDF、DOCX 等格式或套用 Word / LaTeX 模板。采用 GPL-3.0 许可，覆盖 macOS、Windows 与 Linux，可通过 Homebrew、Flathub 等包管理器安装。

## 要点

- **本地优先、无云端依赖**：笔记就是用户文件系统里的普通文本文件，隐私与数据归属由用户自己掌握，不需要账号。
- **引用工作流**：与 Zotero、JabRef 等参考文献管理器集成，在写作时直接插入引用，再配合 Pandoc 生成带参考文献表的 PDF / DOCX。
- **三条导出路径**：Pandoc（多格式转换）、LaTeX（排版级控制）、Textbundle（含资源的可移植包），并支持 Word 与 LaTeX 模板，适配期刊投稿格式。
- **知识管理能力**：原生支持 Zettelkasten 方法论、条目间链接、标签与快速全文搜索，适合长期积累的研究型笔记。
- **技术栈与规模**：Electron + Vue 3 + Pinia + CodeMirror 6 + TypeScript；GPL-3.0 许可；约 13,637 star、848 fork，仓库创建于 2017-12-26，最后一次推送 2026-09-29。
- **平台与开发**：macOS（Intel / Apple Silicon）、Windows x64、Linux（Debian/Ubuntu、Fedora/RHEL、AppImage）；开发需 Node.js 22+ 与 Yarn，界面文案通过 gettext 由社区翻译。
