# 用AI写PPT，没想到效果这么好啊

> 一句话定位：手把手用 CodeBuddy pptx Skill 写 PPT：场景实战与底层工作流拆解。

## 摘要

本文手把手教用 CodeBuddy 的 pptx 技能写 PPT：先盘点缺模板、缺思路、缺资源、没时间四大痛点并引出 Skills 方案；再介绍安装 CodeBuddy 与 document-skills 技能包；随后用无模板、编辑现有、套模板、Word/HTML 转 PPT 四个场景实战展示，53 页 PPT 不到 4 小时完成；最后给出正交拆解、小步迭代、Git 备份等技巧，并拆解 pptx Skill 的 html2pptx、OOXML、模板系统三种工作流及其渲染边界。

## 要点

- 写 PPT 四大痛点：缺模板、缺思路、缺资源、没时间，CodeBuddy Skills 给出 AI 解决方案。
- 装 CodeBuddy（IDE 或 Code）并安装 document-skills 技能包，即可用 pptx 技能写 PPT。
- 四个实战场景：无模板生成、编辑现有 PPT、套模板生成、Word/HTML 转 PPT。
- 使用技巧：清晰表达并正交拆解需求、一次改一个小目标、多轮对话、Git 版本管理。
- 写 PPT 技巧：明确目标受众、搭 Why-How-What 框架、每页突出 1-2 个重点、数据化表达。
- pptx Skill 三种工作流：html2pptx、OOXML 底层编辑、模板系统。
- 设计哲学：HTML 优先、验证优先、工具链化；内置 18 种配色与多种 Web 安全字体。
- 局限：不支持 CSS 渐变与复杂动画，非 Web 安全字体兼容受限。

## 提炼

> 一句话定位：手把手用 CodeBuddy pptx Skill 写 PPT：场景实战与底层工作流拆解。

### 分节提炼

- **01 痛点与解决方案**：写 PPT 四大痛点：缺模板、缺思路、缺资源、没时间。；免费模板丑，付费 99-299 元/套，定制高达 500-2000 元。；Skills 是封装好工作流、工具、脚本的 AI 技能包，document-skills 的 pptx 技能可写 PPT。
- **02 安装与初体验**：CodeBuddy IDE 适合非专业开发者，CodeBuddy Code 适合专业开发者与 Claude Code 用户。；从 GitHub anthropics/skills 安装 document-skills，含 docx/ppt/pdf/xlsx 四种 Skill。；用户级 Skill 全局可用，项目级仅当前项目可用；Code 中可用 /plugin install 命令安装。
- **03 四个实战场景**：无模板场景用 Prompt 生成 HTML 原型再转 PPT，MVP 阶段基本可用。；编辑现有 PPT 可保留背景样式，但字体可能未完全对齐，需手动微调。；套模板生成的 CEO 汇报看不出是 AI 写的；Word/HTML 可直接转 PPT，53 页不到 4 小时。
- **04 使用与写 PPT 技巧**：用 CodeBuddy：清晰表达并正交拆解需求、一次改一个小目标、多轮对话、Git 备份回退。；写 PPT：明确目标与受众，套 Why-How-What 结构，每页突出 1-2 个重点，数据要可视化加解读。；pptx Skill 三种工作流：html2pptx 从零创建、OOXML 底层编辑、模板系统快速套用。；设计哲学：HTML 优先、验证优先、工具链化；内置 18 种配色与多种 Web 安全字体。
- **05 总结**：总结：希望大家摆脱 PPT 之痛，用 CodeBuddy Skills 做出精美原型、作品和 PPT。

### 带走三句话

1. 写 PPT 前先明确目标与受众，再套 Why-How-What 结构搭框架、补细节。
2. 用 CodeBuddy 时正交拆任务、小步迭代、多轮对话，并用 Git 及时备份回退。
3. pptx Skill 三条工作流各司其职：从零用 html2pptx，编辑用 OOXML，套模板用模板系统。
