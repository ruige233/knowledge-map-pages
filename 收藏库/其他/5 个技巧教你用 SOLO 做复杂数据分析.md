# 5 个技巧教你用 SOLO 做复杂数据分析

> 一句话定位：你负责想、Agent 负责做：5 个技巧把复杂数据分析交给 SOLO。

## 摘要

本文把数据分析升级为“你负责想，AI 负责做”。SOLO 的 Agent 凭自主决策、完整执行环境与持久化工作空间承接“做”。五个进阶技巧：一，数据采集+分析一体化，自行取数、装库、查文档、调 API 并出图；二，多 Agent 协作，把可并行任务拆给多个 SubAgent；三，目标驱动，只描述终态与约束；四，AI 校准，出报告前让 Agent 自查数据、模型与结论风险；五，Skill 沉淀，把成功流程打包复用。最后落到“想”的三件事：想清重要问题、验证对错、让 AI 做得更好。

## 要点

- 核心理念升级：你负责定方向、定标准、做判断，Agent 负责规划路径、取数、拆分任务、检查质量、沉淀复用。
- 数据采集+分析一体化：一句话让 Agent 自选 yfinance、装依赖、查文档、调 API、出图，全程无需你懂代码。
- 多 Agent 协作：数据分析子任务天然耦合度低、可并行，400 条评价拆 4 批 SubAgent 并行，18 分 42 秒完成。
- 目标驱动：只描述终态和约束（如最大化利润、至少两种方法），Agent 自主规划，7 分 40 秒产出报告与图表。
- AI 校准：出报告前让 Agent 自查，能揪出口径不一致、样本量不足、模型拟合差、建议价超范围等问题。
- Skill 沉淀：把清洗、指标、图表、报告模板整体打包复用，年度分析复跑从 8 分 29 秒降到 1 分 28 秒。
- 收尾三层“想”：想清楚重要问题、怎么验证对错、怎么让 AI 做得更好。

## 提炼

> 一句话定位：你负责想、Agent 负责做：5 个技巧把复杂数据分析交给 SOLO。

### 分节提炼

- **01 想清楚重要问题**：AI 能算任何你想算的，但“该算什么”只有你能决定。；提问能力是最大杠杆，多花时间想“什么问题值得回答”。
- **02 想清楚验证对错**：AI 做得快不等于做得对：查数据源、筛选条件、样本量、逻辑漏洞。；审校是必选项；AI 做第一轮检查，最终判断力仍需你把关。
- **03 让 AI 做得更好**：新项目管理能力：管理对象从人变成 Agent。；知道何时拆多 Agent 并行、先出方案再执行、沉淀可复用流程。；SOLO 的设计天然匹配“你负责想、AI 负责做”的分工。

### 带走三句话

1. 把目标、标准和判断留给自己，把取数、拆分、检查、复用交给 Agent。
2. 分析完出报告前，加一句“帮我把把关”，让 Agent 做第一轮自查。
3. 把满意的分析流程沉淀为 Skill，下次复跑从 8 分 29 秒降到 1 分 28 秒。
