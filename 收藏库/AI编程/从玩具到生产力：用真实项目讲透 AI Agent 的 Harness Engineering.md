# 从玩具到生产力：用真实项目讲透 AI Agent 的 Harness Engineering

> 一句话定位：用真实项目讲透：Harness 是让大模型成为可交付协作者的工程控制面

## 摘要

本文借 Aegis 项目讲透 Harness Engineering：决定 Agent 企业落地的不是 Prompt 技巧，而是把大模型纳入工程体系的控制面。传统软件工程管确定性，Harness 管非确定性；文章戳破软约束、军火库、盲打重试、官僚文档流等陷阱，给出前置验证、最小真相源、物理门禁正解，企业环境里 Harness 比 Prompt 更重要。Aegis 展示 sdd-riper-one-light 用前置/后置断言与不变式契约锁住非确定性引擎；文末给出 8 阶段 SOP 与照抄句式。

## 要点

- 决定 Agent 成败的往往不是 Prompt 写得多妙，而是 Harness 做得多扎实
- 传统软件工程管确定性，Harness Engineering 管非确定性
- 用执行流路由与状态上下文两个坐标轴可划分四种架构象限，无绝对优劣只有场景适配
- 伪 Harness（软约束、军火库）与劣质 Harness（盲打重试、官僚文档流）是常见避坑对象
- 企业环境容错率低，Harness 比 Prompt 更重要，工程师价值迁移到定义目标、控节奏、做验收
- Aegis 五阶段：先收敛目标、Spec/Handoff 抗上下文腐烂、Prompt 溶解进 Capability、跨能聊与能跑、测试回归前置
- sdd-riper-one-light 用前置断言、后置断言、不变式三大契约锁住非确定性引擎
- 落地路径：先搭真相源、约束边界、构建能力目录、前置验证闭环、完善恢复、逐步释放自由度

## 提炼

> 一句话定位：用真实项目讲透：Harness 是让大模型成为可交付协作者的工程控制面

### 分节提炼

- **01 管确定性还是非确定性**：传统软件工程管确定性，Harness Engineering 管非确定性；大模型是概率引擎，同输入可能幻觉暴走或调错 Tool；Harness 是把非确定性引擎嵌进确定业务流水线的物理控制面
- **02 两轴四象限架构矩阵**：X轴执行流路由：静态预设 vs 动态自主；Y轴状态与上下文：隐式内部 vs 显式外部；四象限：无状态链/提示词驱动/传统管道/Harness，无绝对优劣只讲适配
- **03 伪与劣质 Harness 陷阱**：伪 Harness：软约束陷阱与军火库陷阱；劣质 Harness：盲打重试与官僚主义文档流；好 Harness：Evaluator 沙盒、Spec is Truth、Checkpoint 门禁
- **04 企业环境更需要 Harness**：本地 Demo 缺陷可被人工兜底掩盖，企业环境容错率低、链路长、边界严；Agent 挑战转为：调对接口、失败时自读日志定位、上下文可被人类随时接管；工程师核心价值从亲手写代码迁移到定义目标、卡边界、控节奏、验收结果
- **05 Aegis 五阶段演进**：起步先读架构文档并复述需求，收敛目标与边界，不急着编码；Spec 与 Handoff 是外部持久化记忆，对抗跨天上下文腐烂；一个 Capability=专属 Prompt+脚本+Validator，Prompt 溶解进路由；运行期静默退出/504/403 靠转成可诊断链路排错，测试与回归前置化
- **06 sdd-riper-one-light 骨架**：SDD 是人机协作方法论与工具，Harness 是承载它的底层架构；sdd-riper-one-light 用契约式设计把非确定性引擎夹进确定性管道；前置断言拦输入失控、后置断言拦输出幻觉、不变式对抗跨周期状态腐烂
- **07 顶级团队的 Harness 共识**：OpenAI：情境是稀缺资源，代码仓库 docs/ 文档成为唯一记录系统；Anthropic：强制 Context Resets，独立 Evaluator 提供外部真相；deer-flow：自称 Super Agent Harness，模型大脑与执行环境物理隔离
- **08 从 0 到 1 落地路径**：先搭真相源、约束执行边界、构建最小能力目录；前置验证闭环、完善恢复机制、逐步释放自由度；警惕全自治陷阱：先铺好轨道，再追求自动化速度
- **09 总结**：AI Agent 工程命题是把非确定性超级大脑纳入严谨可预测可迭代的工程体系；人类工程师从执行者升级为体系的控盘者；最有价值的是定义目标、约束非确定性、抓住关键结构并把结果交付的人
- **10 实操方法精华版**：8 阶段 SOP：目标收敛、状态恢复、上下文装配、任务分块、链路设计、执行前校准、外部验证、回写交接；同时盯三层目标：总核心目标、阶段性核心目标、本轮动作目标；偏航四信号：绕阶段目标、跳中间产物、主观替代证据、混淆阶段与全局完成；提供起手收敛、压最小 spec、Checkpoint、基于证据验证等可照抄句式
- **11 延伸阅读与参考资料**：正文讲理念，附录给三份可深入阅读的一手工程实践链接；三份为 OpenAI、Anthropic、deer-flow 一手实践

### 带走三句话

1. Harness 是控制面不是提示词：真相源、边界、能力、观测、验证一个都不能少
2. 先铺轨道再放权：复述目标、交中间产物、Checkpoint 授权、用日志与测试验收
3. 工程师从执行者升级为控盘者：可以不写每行代码，但不能放弃关键点的技术判断
