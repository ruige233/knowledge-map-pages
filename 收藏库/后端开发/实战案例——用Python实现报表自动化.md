# 实战案例——用Python实现报表自动化

> 一句话定位：用 pandas 合并多表数据、xlwings 美化输出 Excel 报表的自动化实战

## 摘要

作者从手工填报周报、月报的痛点出发，演示用 Python 自动化生成 Excel 报表：原始数据为统计局下载的原煤、原油、天然气三个 sheet，指标含产量当期值、累计值、同比增长与累计增长。先用 pandas 读取并 merge 三表、筛选目标列，再用 xlwings 新建工作簿写入数据，并对比逐单元格、逐行、整表数组三种写入方式。随后用 describe() 求各列均值，定位大于/小于均值的数据在 Excel 中的位置，最后统一格式：数据区宋体加边框、首行白字黑底、大于均值标红、小于均值标蓝，保存输出。作者提醒真正项目更复杂，需持续学习。

## 要点

- 报表繁琐重复，人工填报多个 Excel、多个 sheet 耗时费力，适合自动化
- 用 pandas 读取原煤、原油、天然气三个 sheet，并按指标列 merge 合并、筛选目标列
- xlwings 可读写 Excel、修改单元格格式，且能与 pandas 无缝衔接
- 写入 Excel 有逐单元格、逐行、整表数组三种方式，作者推荐整表二维数组写入
- 用 describe() 求均值，把大于/小于均值的数据定位成 Excel 单元格坐标
- 用 sht.range().api 统一设置宋体、边框、字体颜色与单元格底色
- 大于均值标红、小于均值标蓝，最后 wb.save 保存结果并 close

### 分节提炼

- **01 全文**：全流程为：pandas 读三表并 merge 筛选，xlwings 建簿写入，再统一改格式后保存；三种写入方式中整表二维数组最简洁，逐单元格、逐行方式需注意行列位置对应；借助 describe() 求均值，把满足条件的 DataFrame 行索引换算成 Excel 单元格坐标；用 range().api 控制字体、边框、颜色，实现首行黑底与大于/小于均值的红蓝标注

### 带走三句话

1. 报表自动化先合并数据再统一写格式：pandas 管数据，xlwings 管 Excel 格式
2. 整表二维数组写入比逐单元格、逐行更简洁，注意 DataFrame 与 Excel 位置对应
3. 格式美化集中在 range().api 的字体、边框、颜色设置，最后 wb.save 保存
