# 好用！这些工具国庆一定要研究下「GitHub 热点速览」

> 一句话定位：HelloGitHub 国庆特刊：盘点本周值得研究的热点开源项目

## 摘要

本文是 HelloGitHub 2023 年第 38 周的 GitHub Trending 速览，按 release 时间分类，14 天内发布标注 New。本周特推：OpenTofu 是 Terraform 的开源分支，捐献给 Linux 基金会，延续基础设施即代码；Gitness 集成源代码管理与 CI/CD。Trending 周榜：Bevy 为周增 600+ star 的 Rust 游戏引擎；Kamal 借 Traefik 与 SSHKit 实现任意主机零停机部署；InstaGraph 基于 Flask 和 GPT-3.5 把文本或 URL 转成知识图谱；Unifree 可把 Unity 项目迁往其他引擎但尚未发布版本；HyperDX 周增 4000+ star，统一会话回放、日志、指标与追踪。热评介绍数据库子集工具 Jailer 与 Swift 骨架屏库 SkeletonView。

## 要点

- 本期为 HelloGitHub 2023 年第 38 周 GitHub Trending 速览，按 release 时间分类，14 天内项目标注 New。
- OpenTofu 是 Terraform 的开源分支，已捐献给 Linux 基金会，提供基础设施即代码能力。
- Gitness 一体化开发者平台，集成源代码管理、持续集成与持续交付，支持 Docker 部署。
- Kamal 借助 Traefik 与 SSHKit，可在任意主机上零停机部署容器应用。
- InstaGraph 基于 Flask 和 GPT-3.5，把文本或 URL 转成知识图谱可视化。
- Unifree 可将 Unity 项目迁移到其他游戏引擎，但尚处早期阶段、未发布任何版本。
- HyperDX 统一会话回放、日志、指标与追踪，由 ClickHouse 支撑，快速定位生产问题。
- 热评项目 Jailer 做数据库子集提取，SkeletonView 提供 Swift 骨架屏方案。
