# 美团一面：一个线程 OOM 后，其他线程还能运行吗？

> 一句话定位：单线程发生堆溢出 OOM 后，其他线程仍能运行

## 摘要

本文分析美团面试题“一个线程 OOM 后，其他线程还能运行吗？”。作者指出 OOM 分多种类型，如堆溢出、永久代溢出、无法创建新线程等，本文聚焦堆溢出的影响。通过示例代码演示：线程一持续向 ArrayList 添加 1MB 字节数组导致堆溢出，线程二正常休眠打印。运行结果显示 Thread-0 抛出 OutOfMemoryError: Java heap space 后，Thread-1 仍持续输出，堆使用量急剧下滑。结论是：发生 OOM 的线程一般会死亡并被终结，其持有的堆对象被 GC 回收、释放内存，因此不影响其他线程运行；栈溢出结论相同。但 OOM 前会触发 GC，即使其他线程正常工作，也会因频繁 GC 受到较大影响。

## 要点

- OOM 有多种类型：堆溢出、永久代溢出、无法创建新线程等，本文聚焦堆溢出。
- 面试题答案是：一个线程 OOM 后，其他线程还能运行。
- 示例中 Thread-0 持续分配 1MB 字节数组入 list，最终抛出 Java heap space。
- Thread-0 抛 OOM 后，Thread-1 仍按 1 秒间隔持续打印输出。
- 发生 OOM 的线程一般会死亡终结，其持有的堆对象被 GC 回收释放。
- OOM 前会先进行 GC，其他线程会因频繁 GC 受到较大影响。
- 栈溢出的结论与堆溢出一致。

## 提炼

> 一句话定位：单线程发生堆溢出 OOM 后，其他线程仍能运行

### 分节提炼

- **01 全文**：通过两线程示例证明：单线程堆溢出 OOM 后其他线程仍能运行。；OOM 线程持有的堆对象会被 GC 回收，释放内存资源。；OOM 前会触发 GC，其他线程会受频繁 GC 影响。

### 带走三句话

1. 单个线程 OOM 只会终结该线程，其堆内存被 GC 回收，不影响其他线程运行。
2. OOM 分堆溢出、永久代溢出、无法创建新线程等类型，需先区分场景再下结论。
3. OOM 前会触发 GC，其他线程虽能运行，也会受频繁 GC 拖累。
