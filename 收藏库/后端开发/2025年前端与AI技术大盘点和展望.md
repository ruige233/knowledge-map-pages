# 2025年前端与AI技术大盘点和展望

> 一句话定位：2024 前端与 AI 技术全景盘点及 2025 展望：语言、框架、基建、运行时、AI 与跨端趋势。

## 摘要

本文由应用宝前端 MoonWebTeam 团队整理，盘点 2024 年前端与 AI 进展并展望 2025。语言上 TS 5.4–5.7 与 ES2024 持续完善；框架上 React 19、Vue 3.5、Svelte 5、Angular 19 相继发布并向 Signal 趋同；基建 Rust 化加速，Vite 6、Rolldown、RsBuild、Oxlint 涌现；Node.js 仍为运行时之王。AI 大模型百花齐放，Agent 与 AI 编程工具兴起，OpenAI、Gemini、DeepSeek 各领风骚；跨端、低代码、D2C、WASM、音视频同步演进。2025 年大模型赋能、TS 化、Rust 化、一码多端趋势持续。

## 要点

- TypeScript 5.4–5.7 与 ECMAScript 2024 发布，NoInfer、自动类型守卫、Map.groupBy、Promise.withResolvers 等新特性完善开发体验。
- 主流框架 React 19、Vue 3.5、Svelte 5、Angular 19 相继发布，均聚焦性能与开发体验优化，响应式系统向 Signal 趋同。
- 前端基建 Rust 化势不可挡：Vite 6.0 发布、Rolldown 开源，RsBuild、Rust Farm、Oxlint、Biome 等工具性能亮眼。
- Node.js 22/23 支持 require 导入 ESM 与原生 TS，仍为运行时之王；WinterJS 登场，Bun、Deno 强化 Node 兼容。
- AI 大模型百花齐放：DeepSeek-V3/R1 以低成本与强化学习突破推理，OpenAI o1/o3、Sora、Gemini 2.0 多模态进展显著。
- AI Agent 与 AI 编程工具（Devin、Cursor、Windsurf、Continue、Cline）兴起，推动人机协作与意图驱动开发。
- 跨端领域 React Native 新架构、Tauri 2.0、Kuikly 一码六端，原生鸿蒙公测催生跨端框架适配需求。
- 低代码、D2C、WASM、音视频（AV1）等方向同步演进；2025 展望大模型赋能、TS 化、Rust 化、一码多端等趋势。

## 提炼

> 一句话定位：2024 前端与 AI 技术全景盘点及 2025 展望：语言、框架、基建、运行时、AI 与跨端趋势。

### 分节提炼

- **01 年度回顾总览**：总览八大方向：大模型、语言标准、框架、基建、运行时、跨端、低代码/D2C、底层能力。；全文由应用宝前端 MoonWebTeam 团队整理，文中"今年"指 2024 年。
- **02 语言与标准**：Python 成 GitHub Top1，但 JS/TS 仍稳居 Top3，前端热度不减。；TS 5.4–5.7 新增 NoInfer、自动类型守卫与可疑代码真值检查。；ES2024 新增 Map.groupBy/Object.groupBy 与 Promise.withResolvers。；CSS 热门三特性：:has() 选择器、容器查询、原生嵌套。
- **03 前端框架**：四大框架领跑，Svelte 已连续三年超过 Angular 居第三。；React 19 带来 RSC、Compiler 与 Actions；Vue 3.5 优化响应式与解构。；Svelte 5 用 Runes 转向运行时响应式；Angular 19 引入增量水合等。；HTMX 成明星项目但国内大前端适配受限；Astro 5 引入内容层与服务岛。
- **04 前端基建 Rust 化**：Rust 以 82% 青睐度居最受推崇语言，前端工具 Rust 化加速。；Vite 6.0 发布，Rolldown 开源且比 esbuild 快约 1.4–2 倍。；RsBuild 生产可用，Lightning CSS 使 CSS 编译提速 70 倍。；Farm 1.0 支持懒编译与局部打包；Oxlint 比 ESLint 快 50–100 倍；Biome 与 Prettier 兼容 97%。
- **05 JS 运行时**：Node 22 支持 require 导入 ESM，23 默认启用，帮助老项目平滑迁移。；Node 23 原生支持 TS（实验性），并弃 32 位 Windows、升级 V8。；WinterJS 兼容 WinterCG，首个可在 Wasmer Edge 运行的生产级运行时。；Bun 支持 Windows 并提升 Node 兼容；Deno 2.0 全面拥抱 Node/npm。
- **06 Chrome 浏览器**：Chrome 接入 Gemini Nano 本地 AI，DevTools 可用 AI 分析错误与调试 CSS。；CSS 锚点定位支持单/多锚点与 inset-area 九宫格布局。；Web SQL 已完全弃用，建议改用 Wasm SQLite 或 IndexedDB。；DevTools 围绕性能面板、元素面板与 Gemini 升级。
- **07 AI 大模型**：AI Agent 由基础模型+工具调用+记忆+决策框架构成，能自主规划执行。；Devin、Cursor、Windsurf、Continue、Cline 等 AI 编程工具重构开发流程。；OpenAI o1/o3、Sora、Canvas 与 Gemini 2.0 Flash 多模态与工具集成突破。；DeepSeek-V3 低成本、R1 用纯强化学习实现推理里程碑。
- **08 跨端技术**：RN 新架构用 JSI 替代 Bridge，移除 JSON 序列化损耗并支持同步调用。；Tauri 2.0 支持移动端；Kuikly 基于 KMM 实现一码六端。；原生鸿蒙公测推动跨端框架适配，Taro 支持原生渲染方案。
- **09 低代码**：低代码以可视化+模型驱动加速开发，全球渗透率超 50%。；AI 赋能：代码纠错优化、智能提示建议、模板生成与文生应用。；基于组件与 Prompt 生成 DSL 的产品落地，如微信云模板。
- **10 D2C**：传统 D2C 生成静态代码语义化差、可读性可维护性差。；AI+D2C 两种模式：AI 优化语义化、图片+问答式生成与调整。；成熟方案基于 Figma/Sketch，代表产品有 semi、海豹、ImageCook。
- **11 WASM**：组件模型规范模块格式与链接，解决跨语言互操作与模块化。；GC 支持让 TS/Java/Kotlin/Python 免带虚拟机编译运行。；WASI 提供文件、时钟、网络等系统接口，增强跨平台与安全。；应用拓展至 Web 优化、多语言、云原生、游戏与 AI 大模型。
- **12 音视频 AV1**：AV1 开放免版税，比 H.265 省约 10%–40% 码率。；编码耗时约为 H265 三倍，硬解支持率低致软解耗电。；云游戏场景因延迟与硬编门槛暂无法大规模应用。
- **13 2025 展望总览**：承上启下：基于 2024 复盘对 2025 各细分领域作展望。；共提出 7 条趋势判断。
- **14 大模型持续赋能**：人机协作开发已成主流，Chrome、低代码、D2C 均获 AI 赋能。；开发者应主动拥抱并思考如何利用大模型。
- **15 拥抱 TypeScript**：TS 持续蚕食 JS 份额，反 TS 呼声未阻挡其前进。；类型系统能提高项目健壮性与可维护性。
- **16 框架趋同**：四大框架仍是主流，设计理念与 API 相互借鉴。；以 Svelte 响应式重构为例，框架趋同趋势明显。
- **17 基建 Rust 化延续**：Rust 高性能使其成前端基建新宠。；RsBuild、Rspack、Rolldown 等 Rust 工具将愈发普及。
- **18 Node 兼容仍是关键**：Node 因生态完备仍是 2025 运行时首选。；挑战者须支持从 Node 平滑迁移才可能吸引开发者。
- **19 一码多端**：鸿蒙推广下代码共享、一码多端需求更迫切。；2025 跨端领域将有进一步发展。
- **20 AI 引领变革**：大模型多模态与推理能力提升将引领更多颠覆性变革。；Agent 深化融入开发工具链，催生新职业与技能需求。；程序员需在依赖 AI 的同时保持基础编程能力。

### 带走三句话

1. 2024 没有革命性明星项目，但各细分领域持续深耕：语言、框架、基建、运行时、AI、跨端均稳步演进。
2. 大模型正重塑前端：人机协作成主流，AI 编程工具与 Agent 兴起，开发者重心转向业务与架构。
3. 拥抱 TypeScript、基建 Rust 化、一码多端与 Node 兼容是 2025 年最值得跟进的趋势。
