# 小心！电脑截图里面掺了东西！

> 一句话定位：数字盲水印可嵌入截图肉眼不可见，用于泄露溯源，附 blind-watermark 用法。

## 摘要

文章介绍数字盲水印技术：在图片和屏幕截图中嵌入肉眼不可见的水印，用于追踪来源和保护知识产权。大厂如百度、奇安信、360 会在聊天软件、内部网站甚至整个屏幕加水印，可见水印起震慑，不可见水印用于暗地溯源。文章由阿里月饼事件引出图片水印溯源话题，介绍开源项目 blind-watermark：基于频域实现数字盲水印，用 Python 演示——WaterMark 设置密码、读取原图与水印后 embed 嵌入，再用 extract 按水印长度提取。作者强调频域水印抗攻击能力强，裁剪、缩放等场景都能保留；公司电脑普遍预装 EDR 并强制截图且无法关闭。因此用公司电脑截图要当心，避免泄露敏感内容被追溯。

## 要点

- 数字盲水印能在图片和屏幕截图中嵌入肉眼不可见的标识，用于泄露追踪和知识产权保护。
- 百度、奇安信、360 等大厂会在聊天软件、内网甚至整个屏幕加水印，可见水印起震慑、不可见水印用于溯源。
- 开源项目 blind-watermark 基于频域实现数字盲水印，提供嵌入与提取能力。
- Python 用法：用 WaterMark 设置密码、read_img 读图、read_wm 读水印、embed 嵌入、extract 提取。
- 频域水印肉眼不可见且抗攻击能力强，常见的裁剪、缩放等场景都能保留。
- 公司电脑普遍预装 EDR 类产品，屏幕截图是必备功能且无法关闭。
- 用公司电脑截图需谨慎，避免泄露敏感内容导致被溯源追责。
